# 개발 교훈

파일 이름표는 실제 학생 신원을 뜻하지 않습니다. 아래 기록은 개발 과정의 오류와 방지 규칙이며, 성적이나 독립 검증의 전체 결과를 수록하지 않습니다.

| 상황 | 실수 | 교훈 | 방지 규칙 |
|---|---|---|---|
| 동그라미 조각 면제(사용자안) | 독립 검증에서 파일 이름표 사용자3, 스캔0032의91번 동그라미 조각을 1(0.874)로 잘못 자동확정 | 개발 자료에서 통과한 완화가 다른 자료에서는 오확정을 낼 수 있다 | 기본값은 제안안, 사용자안은 참고용으로 유지 |
| 재판독 충돌 완화(E) | 원판독이 여러 숫자인 문항(51번 ①②③, 61번 ①④)까지 완화 | E는 원판독이 숫자 한 글자일 때만 허용 | ee9b407의 단일 1~5 또는 ①~⑤ 조건 유지 |
| 선택 표시 첫 구현 | 98e6ff3 제안안의 추천31개 중 전사 일치21개(67.7%, 약68%). 추가 잉크에서 취소선을 측정해 인쇄 제거 지점에서 선이 끊기고 취소선 검출0개 | 정렬된 300dpi 문항 이미지에서 인쇄 번호를 템플릿 매칭으로 직접 찾고, 취소선은 인쇄와 학생 잉크가 함께 있는 영상에서 측정 | mark_ref.py의 기준 목록41개 재현 후 복수 정답3개 제외. 문항별 조정 금지, 추천은 근거에만 기록 |

세 번째 사례는 취소선 영상뿐 아니라 해상도와 번호 탐색 방법도 함께 수정한 결과입니다. 68%의 원인을 하나로 분리해 측정한 실험은 아닙니다. mark_ref.py와 스캔 유래 템플릿은 로컬 전용입니다.

## 보류한 접근(해커톤 뒤 재검토)

개발91·104번 추가 완화(f5fed75 원인 분석 (비공개 기록)) — 91번은 분리된 호의 닫힘·숫자 포함 관계가 증명되지 않고,104번은 같은 답 표시가 아닌 가로줄이 원인이다. 해당 문항만 통과시키는 예외를 만들지 않으며, 일반화 가능한 규칙과 별도 안전 검증 없이 추가 완화하지 않는다. 해커톤 뒤 재검토한다.
