# 남은 일정의 로컬 유형 판별 AI 가능성

확인: 2026-09-24 11:04 KST경. 마감2026-09-28 오전, 정확한 시각 미정. 약4일 범위입니다. 평가 대상은 최근 대화의 시험지 유형 판별 모듈이며 OCR전체 또는 M1/M2완성의 가능성으로 확대하지 않습니다.

## 실제 확인

- 개발PC: Intel i5-12400F 6코어12스레드, RAM31.8GiB, NVIDIA RTX3080 VRAM10240MiB. 조회 당시 GPU여유8159MiB, 드라이버610.88. 가용량은 변동합니다.
- 기존 프로젝트는 로컬 PaddleOCR CPU추론 실행 기록이 있습니다. 이 결과가 새 로컬 언어/분류 모델의 GPU호환성 검증은 아닙니다.
- private/paddle-env Python환경에서 torch, transformers, sentence_transformers, setfit, sklearn 모듈은 확인되지 않았습니다. Ollama·llama-cli도 PATH에서 확인되지 않았으며 PC전체 설치 부재를 단정하지 않습니다.
- 실제 교재 표본은 있으나 유형 판별용 학습/개발/별도평가 세트는 아직 정리·확정된 것으로 확인되지 않았습니다. 같은 교재의 페이지·유사 문항을 나눠 독립 평가라고 부르지 않습니다.
- 이번에는 읽기 전용 환경 확인과 공식 자료 조사만 수행했습니다. 모델 다운로드·설치·학습·추론 벤치마크는 하지 않았습니다.

## 범위별 판단 — 추정, 완료 약속 아님

| 범위 | 남은 일정 판단 |
|---|---|
| 규칙 기반 로컬 판별기 | 구현·제한 표본 검증을 일정 목표로 둘 수 있음. 학습형AI라고 부르지 않음 |
| 기존 소형 로컬 모델을 불러 유형을 선택시키는 시제품 | 하드웨어·공개 실행 경로상 현실적인 후보. 환경 호환성·한국어 OCR입력 성능을 먼저 실제 시험해야 함 |
| 기존 다국어 인코더 기반 분류기 추가 학습 | 학습 실행까지는 검토 가능. 교사 라벨과 별도 교재 평가 자료 준비가 조건. 일반화된 품질 확정은 아직 근거 없음 |
| Jev/ChatGPT 같은 범용 판단모델을 처음부터 훈련 | 현재 자료·기간에 실용 품질까지 만들 수 있다는 근거 없음. 이번 모듈에 과도한 범위 |
| 유형AI+정확한 서술형OCR+M1/M2앱 모두 완성 | 유형AI 가능성과 별개. 현재 영역 추출·OCR오류·미구현 앱 때문에 기한 내 완성을 보장할 근거 없음 |

GPU10GB·RAM32GB는 소형 모델 시험을 시도할 근거이지 모든 모델/배치/문맥길이에서 실행된다는 보장이 아닙니다. 실제 배포PC 사양은 별도 확인이 필요합니다.

## 기술 후보 근거

- [Qwen3-0.6B 공식 모델 카드](https://huggingface.co/Qwen/Qwen3-0.6B): 기존 소형 다국어 모델을 로컬에서 실행하는 공개 경로가 있습니다. 무학습 초기 시험 후보이며 우리 유형 판별 정확도는 미확인입니다. 최종 모델로 선택하지 않았습니다.
- [SetFit 공식 소개](https://huggingface.co/blog/setfit), [공식 저장소](https://github.com/huggingface/setfit): 기존 문장 인코더를 소수 라벨로 미세조정하는 분류 방식이며 다국어 체크포인트 사용이 가능합니다. 공개 벤치마크의 예제 수·속도를 우리 한국어 교재의 요구량·학습시간·성능 보장으로 옮기지 않습니다.

권고는 처음부터 AI를 훈련하기보다 **기존 소형 로컬 모델+판단 보류+확인 화면**을 먼저 시험하고 규칙 기준선과 비교하는 것입니다. 별도 시험지에서 실패하면 짧은 일정에 추가 학습을 반복하기보다 교사 유형 확인을 남기는 대안을 제시하되 사용자 요구 완료로 표현하지 않습니다.
