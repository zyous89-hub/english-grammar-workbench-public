## 사용자 확정

## Tesseract 설명 보완

Tesseract도 기존 모델 추가 학습과 로컬 모델 실행을 지원합니다. 앞선 답변에서 PaddleOCR만 예로 든 것은 설명이 불충분했습니다. Tesseract 공식 tesstrain은 START_MODEL을 이용한 추가 학습, 줄 이미지·전사 자료, traineddata 생성 방식을 설명합니다. 공식 FAQ는 모델의 로컬 경로를 안내하는 한편, 인쇄체 중심 설계이므로 손글씨 인식 성능에 한계가 있다고 명시합니다. 추가 학습 지원 여부와 우리 학생 필기에 대한 적합성은 별개입니다. 실제 비교 시험은 하지 않았습니다.

## 일정 판단 — 추정이며 약속·확정 범위 아님

현재 앱과 실제 시험 결과가 없고 숙제·답지 표본도 미확보입니다. 처음부터 손글씨 모델을 학습하여 실용 성능을 확보하고 M1/M2 전체를 완성·검증하는 작업은 3일 완료를 약속할 근거가 없습니다. 추가 학습을 한번 실행하는 것과 일반화된 성능을 확보하는 것도 다릅니다.

기존 로컬 OCR을 연결한 제한 범위의 시제품은 3일 개발 목표로 검토할 수 있습니다. 조건은 착수 시 실제 표본과 검토 가능한 기준 답 확보, 지원 문제지·답안 형태 제한 합의, 대상 PC에서 모델 구동, 교사 확인·수정 단계 허용입니다. 표본과 인식 결과를 확인하기 전에는 성공 여부나 지원 비율을 보장하지 않습니다. 교사 확인 중심의 시제품을 자동 채점 전체 목표 완료로 표현하지 않습니다.
