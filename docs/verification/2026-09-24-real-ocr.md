# 실제 자료 최초 OCR 비교 시험 — 실패로 채점 중단

사용자가 학생 JPG, 해당 원본 PDF, 답지 PDF를 제공하고 순차 비교 후 학생 답 추출이 가능할 때만 채점하도록 요청했습니다. 불가능하면 멈추라는 지시를 따랐습니다.

## 수행과 결과

2026-09-24, 기존 설치 Tesseract v5.4.0.20240606, eng, 기본 페이지 분할(3)을 사용했습니다. 학생 JPG 전체 OCR을 먼저 저장하고, 원본 PDF 첫 페이지를 pdftoppm으로 최대 변 1280px 렌더링하여 같은 설정으로 OCR했습니다. 두 문서가 같은 페이지임을 시각 확인한 뒤 답안 위치와 OCR 결과를 대조했습니다. 두 TXT의 unified diff도 생성했습니다.

학생 필기에는 누락·잘못된 문자·취소 흔적 혼입이 있었고, 원본의 빈 답란에서도 가짜 문자가 나왔습니다. 두 텍스트의 차이만으로 학생 답을 안정적으로 추출하지 못했습니다. 이 방식의 채점 진입 조건을 충족하지 못해 중단했습니다. 답지 PDF는 열지 않았으며 점수·정답률은 산출하지 않았습니다. 실제 학생 필기 내용·원자료·OCR 전문은 GitHub에 포함하지 않았습니다.

## 근거와 한계

로컬 private/ocr-real-20260924/에 입력 해시·환경·명령 metadata.json, 학생/원본 TXT·TSV, 원시 텍스트 차이, 원본 렌더 이미지, 시각 확인용 학생 답 확대 이미지, 사례별 보고서를 보존했습니다. 이 경로는 Git 제외이므로 저장소만 복제하면 실제 원자료 증거는 없습니다.

원본 정렬·이미지 차분이나 다른 손글씨 모델을 시험한 결과는 아닙니다. 시각적으로 판독한 답을 OCR 결과로 대체하지 않았습니다. 학생 답 확대는 검토용이며 영역 재인식은 실행하지 않았습니다. eng만 설치되어 한국어 결과는 평가하지 않았습니다. 네트워크 차단·송신 감시와 처리 시간 측정은 미실시입니다. 콘솔에서 특수문자 출력 인코딩 오류가 한번 발생했으나 OCR 결과 파일에는 영향을 주지 않았고 UTF-8 출력으로 위치 목록 조회를 재실행했습니다.

## 상태 변경

실제 입력 표본이 최초 확보됐습니다. 이전 문서의 자료 미제공은 당시 기록입니다. 앱은 여전히 미구현입니다. 이번 실패를 모든 OCR 또는 원본 이미지와의 비교 방식 자체가 불가능하다는 결론으로 확대하지 않습니다. 사용자 지시에 따라 이번 시험을 종료하며 다른 엔진·추가 학습을 자동으로 이어서 실행하지 않습니다.
