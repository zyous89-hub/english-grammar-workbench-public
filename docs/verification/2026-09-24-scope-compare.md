## 평가 기준과 입력

주관식은 기존 비교급 단어 답안과 관계부사 문장/단어 표본을 사용했습니다. 비교 전사는 새 OCR 실행 전에 입력 이미지를 보고 별도 파일에 보존했지만 이전 개발 자료에 노출된 assistant의 임시 전사이며 독립 정답이 아닙니다. 애매한 단어1개·문장 줄2개는 불일치 분모에서 제외했습니다. 비교급6문항 전사는 사용자 확인을 요청했으며 작성 시점 답변 대기입니다.

이전 수동 지정 객관식 번호9조각, 단어29조각, 문장 줄15조각, 합계53개를 기존 CPU PP-OCRv5_server_rec에 원래 이미지/전역 Otsu 흑백처리 두 조건으로 넣었습니다(106개 인식). 문장 영역은 수동 분할과 이전 경계 수정이 포함됩니다. 비교급 영역은 기존 원본 밑줄·인쇄 줄 경계를 사용한 결과입니다. 새 이미지106개나 새 학생106명으로 세지 않습니다. 오류 사례를 의도적으로 포함한 개발 비교이며 무작위 표본·독립 일반화 평가가 아닙니다.

일괄 흑백 처리는 이번 표본에서 악화돼 기본 인식 경로로 채택하지 않습니다. 두 조건이 같은 오출력을 내는 사례도 있으므로 출력 일치만으로 자동 확정하지 않습니다. 학생별 전사와 원시 문자열은 로컬 보고서에만 보존합니다.
