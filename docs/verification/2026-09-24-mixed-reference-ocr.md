# 객관식·서술형 원본 추가 후 영역 추출 시험

2026-09-24. 사용자가 앞선 전송이 원본 첨부 전 실수였다고 설명한 뒤 문제 원본 PDF2개를 제공했습니다. 둘 다1페이지이며 학생 이미지의 교재 단원·문항 배치와 대응함을 렌더링 시각 확인했습니다. 정답지가 아니므로 채점하지 않았습니다.

## 실제 방법

PDF를 폭1334px로 렌더링하고 학생 스캔을1334×1888로 축소해 SIFT/RANSAC으로 정렬했습니다. 서술형 일치점1530개·중앙 오차0.589px, 객관식838개·0.596px였습니다. 이 값은 정렬 일치점 기준이며 페이지 모든 픽셀의 정확성 보장은 아닙니다.

문항별 넓은 탐색 구역은 원본·학생 대응을 검토하며 수동 지정했습니다. 내부 답안 경계는 원본의 어두운 인쇄 픽셀을 제외한 학생 필기 후보에서 자동 계산했습니다. 객관식은 원 모양에 가까운 연결 성분, 서술형은 필기 후보가 있는 행 묶음을 사용했습니다. 기존 원본 밑줄 위쪽 확장 규칙을 그대로 적용한 시험은 아닙니다. 여러 줄·밑줄 밖 답을 다루기 위한 차이 기반 후보 추출 시험이며 완전 자동 문항 탐지로 표현하지 않습니다.

차이 영상은 좌표 계산에만 쓰고 인식에는 해당 좌표의 학생 원래 해상도 조각을 사용했습니다. 원본 인쇄 픽셀이 사각형 내부에 있으면 OCR 입력에도 남을 수 있습니다. 기존 로컬 PP-OCRv5_server_rec, CPU, MKL-DNN 끔, 10px흰 테두리. 후보23개 인식12.80초, 모델 초기화1.82초이며 PDF처리·영역 추출·검토 시간은 제외했습니다.

## 결과와 실패

- 객관식9문항에서 후보10개를 얻었습니다. 2번 원이 나뉘어2개 후보가 생기고 숫자 판독에 실패했습니다. 나머지8문항은 번호 표기 통일 후 이전 assistant의 시각 판독 번호와 일치했습니다. 교사 정답·채점 정답률이 아닙니다. 이전 수동 영역에서9개 모두 읽힌 것과 구분합니다.
- 서술형10개 답안 단위에서 후보13개가 생겼습니다. 이전 수동 분할18줄과 달리 여러 줄을 한 영역으로 묶거나 끝 획만 별도 영역으로 분리한 실패가 보였습니다. 단일 줄 인식기에 여러 줄 입력이 들어가 출력 누락이 커졌습니다. 일부 짧은 답은 유지됐으나 전체 개선으로 결론 내리지 않습니다.
- 원본을 추가해도 필기 선·밑줄·긴 내림획 때문에 인접 줄이 이어지고, 인쇄 잔여 픽셀도 후보에 섞였습니다. 개선할 병목은 줄·답안 단위 분리이며 모델 문자 인식만의 실패로 집계하지 않습니다.
- JSON 저장 시 NumPy정수 직렬화 오류를 수정하고 다시 실행했습니다. 중복·겹치는 객관식 후보 병합을 추가했지만 2번의 분리 실패는 남았습니다. 실패 출력도 보존했습니다.

Python 연결/DNS 차단 훅에서 연결 시도0회, OS 전체 통신 감사는 아닙니다. 추가 학습·답지 열람·채점은 하지 않았습니다. 자료를 보고 규칙을 수정한 개발 시험이며 독립 평가가 아닙니다.
