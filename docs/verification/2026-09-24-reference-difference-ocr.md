# 원본 기준 변경 영역 인식 시험

2026-09-24. 사용자는 원본을 먼저 활용하여 달라진 부분에 집중하자고 제안했습니다. 파일 순서만 바꾸는 것으로 좁혀 이해한 설명을 정정하고, 원본 이미지 저장·정렬·차분·영역 인식을 실제 실행했습니다.

## 절차

원본 PDF의 기존 렌더 이미지를 기준으로 학생 JPG와 SIFT/RANSAC homography 정렬했습니다. 본문 대응 후보 1078개 중 927개가 inlier이며 해당 점의 중앙 잔차는 약 0.423px입니다. 원본 인쇄 획 마스크를 확장해 제외하고 남은 픽셀을 묶어 변경 영역을 찾았습니다. 정렬용 본문 범위와 검색할 하단 연습문제 범위는 수동 지정했으며 개별 필기 후보 13개는 자동 탐색했습니다. 범용 자동 문항 검출 구현을 의미하지 않습니다.

13개 영역에 대해 인쇄체 제거 이미지와 동일 위치의 원래 학생 이미지 두 종류를 기존 로컬 PP-OCRv5_server_rec로 읽었습니다. 모델 변경·추가 학습·답지 기반 교정은 하지 않았습니다. 초기 준비 스크립트의 수동 답란 조각은 실제 OCR 입력으로 사용하지 않았고 자동 탐색 조각만 읽었습니다.

## 결과

자동 탐색 영역 13개를 실제 답란과 시각 대조했습니다. 원래 학생 이미지 조각 인식은 9/13개, 인쇄체 제거 조각 인식은 5/13개가 기준 전사와 일치했습니다. 양끝 공백만 제외하고 대소문자는 보존했습니다. 기준 전사는 assistant의 이미지 판독이며 답지 정답·학생 점수가 아닙니다. 대소문자를 무시하면 제거 조각은 6/13개입니다. 두 방법에서 잘된 것만 골라 합치지 않았습니다.

원본으로 새 필기 위치를 찾고 원래 픽셀을 읽는 방법이 이 표본에서는 나았습니다. 제거 방식은 손글씨 획을 손상시켰습니다. 원래 조각에서도 문자 혼동·불완전 인식 4개가 남았고 일부는 자동 영역이 희미한 첫 획을 제외한 문제도 있었습니다. 전체 답 추출 조건을 충족하지 못하여 답지는 계속 미열람이며 채점하지 않았습니다.

모델 초기화 1.87초, 제거 이미지 13개 인식 8.68초, 원래 조각 13개 인식 7.08초입니다. 정렬·탐색·검토 등 전체 시간은 측정하지 않았습니다. 이전 전체 페이지 OCR과 작업량이 달라 같은 조건의 속도 비교가 아닙니다. Python 연결/DNS 감사 훅 감지 0회이며 OS 수준 통신 검증이 아닙니다.
