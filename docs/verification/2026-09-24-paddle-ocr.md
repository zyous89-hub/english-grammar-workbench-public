# PaddleOCR 재시험 — 개선됐으나 채점 중단

사용자가 다른 OCR인 PaddleOCR로 재시험하도록 요청했습니다. 학생 JPG와 앞서 확인한 원본 PDF 렌더 이미지를 순서대로 인식했습니다. 답 추출 가능할 때만 답지로 채점한다는 기존 조건을 유지했습니다.

## 실제 실행

- 프로젝트 private 아래 Python 3.11 환경을 만들고 PaddleOCR 3.3.2, PaddlePaddle 3.2.0, PaddleX 3.3.13을 설치했습니다. 기존 다른 프로젝트 환경은 변경하지 않았습니다.
- PP-OCRv5_server_det / PP-OCRv5_server_rec, CPU, MKL-DNN 비활성화, 방향·펼침 보정 비활성화로 실행했습니다. 모델은 PaddlePaddle 공식 Hugging Face 배포본을 사용했습니다. 초기 BOS 다운로드는 느려서 준비 프로세스를 중단하고 배포 경로를 바꿨습니다.
- 모델 초기화 13.57초, 학생 페이지 추론 98.43초, 원본 페이지 추론 107.70초. 단일 실행·비최적화 조건입니다. 설치·다운로드·저장·교사 검토·채점 시간은 추론 시간에 포함하지 않았습니다. 다른 입력으로 측정한 이전 합성 시험 시간과 직접 비교하지 않습니다.
- Python socket 연결/DNS 감사 훅을 적용한 상태에서 로컬 모델 추론을 완료했습니다. 감지한 연결 시도 0회. OS 수준 무통신 검증 완료를 의미하지 않습니다.

## 결과와 중단

기존 Tesseract가 누락·오인한 일부 학생 필기를 읽어 개선을 확인했습니다. 그러나 철자 오인, 선택 기호/숫자 혼동, 취소 흔적 혼입, 인쇄 문제와 답의 영역 병합이 남았습니다. 두 OCR 결과 차이에서 학생 답 후보를 볼 수 있어도 정확한 전체 답 추출을 완료하지 못했습니다. 답지는 미열람이며 채점·점수 산출은 하지 않았습니다. 다른 설정·학습·모델을 자동으로 이어서 시험하지 않았습니다.

학생 원문 및 문항별 표, JSON/TXT, 시각화, 실행 코드·로그·모델 해시는 로컬 private/paddle-real-20260924/에 보존했습니다. GitHub에는 학생 필기·성적·실제 문제 원문 없이 이 절차·결과 요약만 저장합니다. private 증거는 저장소 복제에 포함되지 않습니다.
