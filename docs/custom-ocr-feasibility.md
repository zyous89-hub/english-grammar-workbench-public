# 숙제 채점용 맞춤 OCR 가능성 검토

2026-09-23. 기술 조사와 제안이며 사용자 확정 설계·구현·성능 결과가 아닙니다.

## 결론과 권장 순서

맞춤 OCR을 개발하는 것은 가능합니다. 먼저 기존 로컬 모델로 기준 성능을 측정하고, 답안 영역 분리와 인식 설정을 개선한 다음 필요한 부분만 추가 학습하는 접근을 제안합니다. 처음부터 모델을 학습하는 방법도 있지만, 지금은 실제 표본·정확한 전사·장비·목표 성능이 없어 비용과 효과를 판단할 근거가 부족합니다. 특정 엔진은 선정하지 않았습니다.

1. 실제 JPG 숙제와 PDF 답지를 확인하여 문항·답안 위치를 연결합니다. 인쇄 문장과 학생 필기를 분리하고 원본을 보존합니다.
2. 기존 로컬 OCR 후보로 학생 답안을 그대로 읽는 기준 시험을 합니다. 자동 맞춤법 교정이나 답지 정답에 맞춘 인식 보정은 적용하지 않는 방향입니다. 이런 설정만으로 모델의 문맥 편향이 없어지지는 않습니다.
3. 인식 실패 원인을 위치 검출, 글자 인식, 취소선·화살표와 최종 답 선택으로 나눕니다. 위치 오류를 글자 모델 추가 학습으로 해결했다고 가정하지 않습니다.
4. 실제 글자 인식에 반복 문제가 남으면 해당 표본으로 추가 학습하고, 학습에 사용하지 않은 자료에서 개선 여부를 확인합니다.
5. 검토·수정 시간을 포함한 한 세트 처리 시간과 오채점이 충분히 개선되는지 보고 채택합니다. 충족하지 못하면 지원 범위·확인 절차를 재검토합니다.

## 무엇을 학습시키는가

OCR 학습용 기준은 답지의 정답이 아니라 이미지에 실제로 적힌 글자입니다. 설명용 가상 사례: 학생이 `He gose home.`이라고 썼다면 인식 목표도 `He gose home.`입니다. `He goes home.`을 학습 정답으로 넣으면 오답을 정상 문장으로 바꾸는 방향이 됩니다.

추가 학습에는 이미지와 사람이 확인한 정확한 전사 쌍이 필요합니다. 일부 표본의 초안 전사는 도구로 만들 수 있지만 사람이 원본과 대조해야 합니다. 읽을 수 없는 글씨에 임의 정답을 붙이지 않습니다. 답지만으로 학생 손글씨 학습 자료를 대체할 수 없습니다. 필요한 표본 수와 작업 시간은 아직 산정하지 않았습니다. 어법 분류를 전체 자료에 미리 붙여 오라는 요청과는 별개입니다.

인식 → 답지 대조 채점(M1) → 오답 어법 분류(M2)를 분리합니다. OCR만 추가 학습했다고 문항 연결·취소선 판단·채점·분류까지 해결되는 것은 아닙니다. 교사가 수정한 결과도 검토된 학습 후보로 모을 수 있지만 수정 즉시 운영 모델이 자동 변경되는 설계는 제안하지 않습니다.

## 독립 실행과 검증

모델과 실행 구성요소를 앱에 포함해 로컬에서 처리하는 구조가 가능합니다. 학습도 로컬에서 진행하는 경로를 검토하되 필요한 메모리·GPU·시간은 모델과 장비 확인 후 판단합니다. 학생 자료를 클라우드 학습 서비스에 보내는 방안은 채택하지 않았습니다.

모델 파일이 로컬에 있다는 사실만으로 무통신을 보장하지 않습니다. 자동 다운로드·업데이트·진단 전송 등도 확인하고, 네트워크 차단 실행과 송신 여부 검사를 별도로 해야 합니다. 현재는 미실시입니다.

평가 제안: 문자 오류율, 답안 전체 전사 일치, 오답을 정답으로 처리한 건수, 정답을 오답으로 처리한 건수, 보류율, 교사 수정 시간, 전체 한 세트 시간을 함께 측정합니다. 새 학생에게도 적용할 목적이라면 학생 단위로 학습·평가를 분리하고, 새 문제지 형식에 대한 성능도 별도로 확인합니다. 같은 페이지를 잘라 양쪽에 넣어 성능을 과장하지 않습니다. 수동 채점 시간은 사용자 추후 제공 사항입니다.

## 실제 확인과 출처

- PaddleOCR 공식 문서는 자체 자료를 이용한 모듈별 추가 학습과 학습 후 로컬 모델 경로 지정 실행을 안내합니다: https://github.com/PaddlePaddle/PaddleOCR/blob/main/docs/version3.x/pipeline_usage/OCR.en.md (Custom Development).
- Tesseract 공식 학습 도구는 줄 이미지와 전사 쌍, 기존 모델 추가 학습 및 처음부터 학습하는 방식을 설명합니다: https://github.com/tesseract-ocr/tesstrain/blob/main/README.md (Provide ground truth data / Choose training regime). 이는 학습 가능성의 근거이며 학생 손글씨용 최적 엔진이라는 추천이 아닙니다.

실제 수행: 위 공식 문서 열람과 이 검토 문서 작성. 모델 설치·학습·OCR 실행·학생 자료 검사·정확도 시험·앱 구현은 하지 않았습니다. 엔진 선택과 구체적인 학습 착수는 미정입니다. 자료는 사용자가 나중에 제공하기로 했으므로 이번에 다시 요구하지 않습니다.
