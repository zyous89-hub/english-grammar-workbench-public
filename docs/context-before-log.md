# 기록 시작 이전의 맥락

**이 문서는 현재 대화에 보이는 과거 논의의 요약입니다. 과거 전체 대화의 원문 로그나 당시 작성된 문서가 아닙니다.**

사용자는 기존에 만들었던 HTML 작성 및 어법 분석·분류 스킬을, AI 없이 실행되는 독립 실행형 앱으로 옮기고자 했습니다. SK하이닉스 AI 해커톤 지원 포트폴리오로서의 가치도 논의했습니다.

이후 문제와 정답뿐 아니라 어법 해설까지 제공할 수 있지만, 어법 분류는 제공되지 않는다고 명확히 했습니다. 이에 assistant는 해설 표현과 규칙으로 분류 후보를 제안하고, 교사가 수정·확정한 결과를 HTML로 만드는 방향을 제안했습니다.

앞선 제안 중 분류의 대분류/소분류, 주된 출제 어법/관련 어법의 분리, 규칙 개수, 사례 개수, 개발 도구는 아직 사용자 최종 확정 사항이 아닙니다. 예시 문법 분류명은 기존 스킬의 정확한 분류표를 검토한 결과가 아닙니다.

이 저장소를 준비한 작업에서는 기존 스킬 파일, 소스코드, 실제 답지, 완성 HTML을 수집·검사하지 않았습니다. 초기 문서만 보고 기존 기능의 전부가 파악되었다고 해석하면 안 됩니다.

원문 기록 시작점은 사용자의 '지금부터 나누는 대화를 전부 깃헙에 repo로 저장' 요청입니다.
