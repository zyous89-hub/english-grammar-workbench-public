# 원본 문제 유형 판별용 소형 로컬 모델 비교

2026-09-24 공식 모델 카드 확인. 사용자 요청은 후보의 장단점 비교이며 특정 모델 최종 채택은 아직 없습니다. 아래 우선순위는 assistant의 제안입니다. 다운로드·설치·추론·추가 학습은 이번 작업에서 수행하지 않았습니다.

## 후보와 권고

| Qwen3-4B-Instruct-2507 | 텍스트 입력, 비추론 전용으로 긴 사고 출력 없이 유형·근거를 받기 적합. 공개 로컬 실행 경로, Apache 2.0 | 이미지 직접 입력 불가. 원본 텍스트/OCR 품질에 의존. 2B보다 가중치 규모가 큼 | 첫 시험 후보 |

각 모델의 우리 시험지 정확도 순위는 미확인입니다. 일반 벤치마크를 시험지 유형 분류 성능으로 옮기지 않습니다. Qwen3 4B 우선은 OCR→텍스트 분류 경로와 남은 기간을 고려한 구현 판단이며 성능 우위 실험 결과가 아닙니다. Qwen3.5 2B가 같은 평가에서 충분한 품질과 낮은 자원 사용을 보이면 우선순위를 바꿀 수 있습니다.

## 비용·보안·하드웨어

후속 질문의 GPT-5 mini는 [OpenAI 공식 문서](https://developers.openai.com/api/docs/models/gpt-5-mini)에서 API 모델로 제공됩니다. 로컬 다운로드용 가중치 제공 경로는 확인되지 않았으므로 이번 로컬 후보에서 제외했습니다. mini라는 이름이 PC 설치 가능을 의미하지 않습니다. API 사용을 허용하는 비교에는 포함할 수 있지만 입력의 외부 전송과 사용량 요금이 발생합니다. 앞선 표에서 이 제외 이유를 명시하지 않은 점을 보완합니다.

로컬 추론은 건당 외부 API 요금 없이 구성할 수 있지만 설치·전력·유지보수 비용은 있습니다. 모델별 이용 조건은 별개입니다. 기존에 확인한 RTX3080 10GB·RAM32GB에서 낮은 비트 양자화와 짧은 문맥으로 시험하는 안을 제안합니다. 실제 GPU 메모리·속도·OCR과 동시 실행 가능 여부는 미측정입니다.

모델 이름만으로 무유출을 보장하지 않습니다. 모델과 실행 라이브러리 준비 이후 외부 통신 없이 작동하고 원본·결과·로그가 로컬에 남는지 검사해야 합니다. 최종 앱은 실행 엔진을 통합해 별도 프로그램 조작 없이 사용하는 것이 목표입니다. Jev는 로컬 가중치 제공을 확인하지 못해 후보에서 제외한 상태를 유지합니다.

## 첫 비교 시험 제안

1. 학생 필기가 없는 동일 원본에서 텍스트와 문항별 위치 정보를 준비합니다. 처음에는 이미지 모델도 텍스트 입력으로 비교합니다.
2. 객관식·주관식·혼합·판단 보류와 원문 근거를 출력하게 합니다. 답지와 학생 정답 여부는 입력하지 않습니다.
3. 교사 확인 유형과 비교하고 틀린 유형 확정, 혼합 누락, 보류, 출력 형식 실패를 구분합니다. 모델이 말하는 확신을 검증된 확률로 취급하지 않습니다.
4. 최초 로딩과 이후 처리 시간을 구분하고 최대 메모리·통신 차단 상태를 측정합니다. 이미 본 두 원본은 개발 표본이며 새 교재 평가를 대신하지 않습니다.

이번 모델의 역할은 OCR 경로 선택을 위한 문제 유형 판단입니다. 손글씨 전사나 답지에 맞춘 철자 수정 역할을 주지 않습니다. 추가 학습 없이 먼저 비교하며 학습 필요성은 실패 사례 확보 후 판단합니다.
