assistant 진행 요약: 필기 이미지·OCR 문자·모델 점수 세 열로 바꾸고 내부 기록과 답지 비교는 기본 화면에서 제외한다고 안내했습니다.

실제 작업: tools/render_ocr_review.py로 기존 로컬 DB의 실제 입력 이미지와 연결되는569개 기록을 index.html에 표시했습니다. 원문 score는 유지하며 화면은 소수4자리, 전체 값은 마우스 설명에 제공합니다. 시험 선택·문자 검색·30개씩 보기·이미지 확대를 추가했습니다. DB 및 기존 상세 화면(detailed-index.html)은 보존했습니다. 중복 보고서 인용을 줄였으며 이미지 대응을 확정하지 못한 점수만 있는 기록/전체페이지 배열/과거 덮어쓴 초기 오류 결과/글자별 trace는 이 보기에서 제외했습니다. 전체DB7229개를569개 독립 시험으로 바꾼 것이 아닙니다.

검증:569개 이미지 존재 및 DB에 저장된 SHA256 일치, 3열 구조, JavaScript 문법 검사를 확인했습니다. 도구의 로컬 파일 URL 보안 정책 때문에 브라우저 표시 확인은 차단됐으며 우회하지 않았습니다. 실제 브라우저 렌더/클릭 검증은 미실시입니다. 학생 자료 전송 및 신규 OCR 실행 없음. 작성 이후 최종 발화 미포함.
