# 대화 — 다른 표기 학생의 원본 비교 OCR 시험

2026-09-24. 발화별 시각 미조회.

## user — 앞선 질문 원문

겹쳐서 바뀐 부분을 검증하게 하는게 OCR 수준에서 가능한지?

## assistant — 앞선 설명 요약

원본 대비 변화 검출은 이미지 정렬·비교, 글자 읽기는 OCR, 선택 의미 판별은 별도 기능이라고 설명했습니다. 변화 영상만으로 확정하지 않고 학생 원래 이미지를 함께 확인하는 방향을 제안했습니다.

## user — 현재 요청 요약 (원문 아님)

표기 방식이 다른 학생 자료와 대응 원본 PDF를 제공하고 현재 논리만으로 OCR 시험을 실행해 문제를 확인하도록 요청했습니다. 앞선 JPG만 제공한 요청은 원본 추가와 함께 재전송됐으며, 중단 전에는 파일·기존 코드 확인만 했고 OCR 실행은 없었습니다.

## assistant — 진행 설명 요약

원본 선지 위치 읽기→정렬·차이→선지 위치 연결→OCR출력 확인 순서를 안내했습니다. 수동 지정/미구현 범위를 밝히겠다고 했습니다. 원본40개 번호 등록, 인접 후보 혼입, 전체 페이지 실행 실패와 문자 인식기 직접 실행, 표시 의미 판별 미구현을 차례로 알렸습니다.

## 실제 작업

[시험 기록](../verification/2026-09-24-choice-marks.md)을 작성했습니다. 원형 필수 조건 없는 변화 후보 시험, 원본 선지40개 자동 등록, 기존 로컬 인식기로 학생 조각40개 읽기를 수행했습니다. 전체 페이지 실행 실패·후보 과검출·선택/제외 의미 판별 불가를 보존했습니다. 정답지 열람·채점·학습·외부 전송은 하지 않았습니다. 원본·학생 자료·보고서는 private/에 로컬 보존했습니다. 작성 이후 최종 발화는 포함하지 않습니다.
