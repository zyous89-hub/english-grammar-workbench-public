- 날짜: 2026-09-23 (Asia/Seoul). 개별 발화 시각 미확인.
- 아래 사용자 본문과 assistant 진행 알림은 원문입니다. 마지막 완료 응답은 아직 발화 전으로 제외합니다.
- 도구 출력·내부 추론·인증정보는 제외합니다. 자동 대화 동기화가 아닙니다.

## 001 — user

큰 변화는 a.b.c에서 a를 변경
자잘한 변화는 b를 변경

예를 들어 0.12.0에서 내가 수정할 부분을 찾아서 고치고 그 결과로 두어개를 수정한다면?

## 002 — assistant (진행 알림)

한 번의 리뷰에서 수정사항 두어 개를 받아 함께 고치면 **`0.12.1`**로 저장하겠습니다. 수정 항목 수가 아니라 리뷰를 반영해 제출한 결과 단위로 `c`를 올리는 방식입니다. 이 버전 규칙을 프로젝트에 기록하겠습니다.

## 후속 기록 범위

다음 내용은 후속 턴에 추가했습니다. 직전 완료 답변은 요약이며, 사용자 승인과 진행 알림은 원문입니다. 이번 승인 반영 후 마지막 완료 응답은 수록하지 않습니다.

## 003 — assistant (직전 완료 답변 요약)

리뷰에서 지적한 여러 항목을 한 번에 고치면 0.12.1, 다시 리뷰 후 수정하면 0.12.2로 저장한다고 설명했습니다. 자잘한 새 변화는 0.13.0, 큰 변화는 1.0.0이며 상위 숫자를 올리면 하위 숫자를 0으로 초기화한다고 안내했습니다. 규칙 문서 업로드 확인도 보고했습니다.
