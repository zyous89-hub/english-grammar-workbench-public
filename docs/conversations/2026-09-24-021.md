## 실제 시험

기존 private/mixed-reference-ocr-20260924/regions.json의 동일 23개 조각으로 PP-OCRv5_server_rec CPU, MKL-DNN 끔, batch_size=1 인식을 다시 실행했습니다. 목적은 새로 요청받은 자원 사용 측정이며 정확도 개선 시험이 아닙니다. GPU는 사용하지 않았습니다.

- 개발PC 기존 확인 사양: i5-12400F, RAM 약32GB.
- 라이브러리 import와 모델 준비: 10.36초. 이전 모델 초기화만 측정한 1.82초와 범위가 다름.
- 23개 조각 인식: 13.11초.
- Windows GetProcessMemoryInfo 기준 PeakWorkingSetSize: 404.76MiB.
- 종료 직전 PrivateUsage: 667.70MiB. 물리 RAM 최고 사용량과 별개 지표.
- PDF 렌더링·원본 정렬·영역 추출·앱·전체 OS 메모리는 제외. 전체 숙제 채점 시간이나 최소 사양으로 환산하지 않음.

학생 문자열은 출력하지 않았고 Python 연결/DNS 차단 훅을 적용했습니다. OS 전체 무통신 검증은 아닙니다. private/ocr-resource-probe-20260924.py와 .json에 측정 코드·결과를 보존하며 학생 자료는 Git에 포함하지 않습니다.

## 제안과 사용자 조건

검증 대상 사양 초안은 Windows x64·최근 4코어 이상 CPU·RAM8GB부터, 여유 있게 RAM16GB·SSD입니다. 구매 권고나 보장된 최소 사양이 아니며 해당 사양 실제 PC에서 전체 파이프라인 시험이 필요합니다. 현 인식 모델에는 전용 GPU가 필수가 아니지만 향후 모델 교체 시 재평가합니다.

사용자는 학생 데이터가 외부로 나가지 않는 조건에서 API 활용에 긍정적인 반응을 보였습니다. 유형 판단용 원본 지시문·선지 구조만 전송하는 설계로 구체화합니다. 학생 이름·식별자·필기·성적·파일명·메타데이터·오류 로그 등은 전송 대상에서 제외합니다. 학생 스캔에서 이름 부분만 자르는 방식 대신 필기 없는 별도 원본을 사용하고 필요한 텍스트만 추출하는 것을 기본 제안으로 둡니다. 실제 API 제공자·모델·지출 한도는 미정이고 이번 API 호출·전송·과금은 없습니다.
