# 대화081 — 상호작용 가능한 OCR 규칙 검토 HTML

## 사용자 요청 원문

> 규칙 목록을 상호작용 가능한 html파일로 작성해줘
> 내가 거기에
> 1) 추가질문
> 2) 수정 요청 + 내용
>
> 이런걸 쓰고 그걸 json/텍스트로 복사해서 여기에 바로 줄 수 있도록

## 결과

[검토 HTML](../ocr-rule-review.html)을 생성했습니다. 외부 라이브러리·서버 없이 파일을 직접 열어 사용합니다.079 원문의72규칙 ID·규칙·출처를 그대로 포함하고 전체 의견 칸을 추가했습니다. 검색/단계 선택/작성한 항목 필터, 규칙별 질문과 수정 요청, 이전/다음 이동을 제공합니다.

‘의견 복사 / 저장’에서 작성한 내용만 JSON/텍스트로 모읍니다. 필터로 가려진 의견도 포함합니다. 규칙 ID·원문·출처·질문·수정 요청·목록버전·원문해시를 출력합니다. 전체 의견은 별도 필드입니다. 클립보드 복사와JSON/TXT다운로드가 가능하며 복사가 차단되면 내용을 전체 선택해 수동 복사를 안내합니다. 입력은textContent/textarea로 표시하여 HTML로 실행하지 않습니다.

브라우저localStorage에 문서해시별로 임시 저장하며 저장이 제한되면 경고를 표시합니다. HTML파일 자체에 의견이 기록되는 것은 아닙니다. 동일 브라우저/주소 외 영구 보존을 보장하지 않고 중요한 의견은복사/파일저장을 안내합니다. 사용자가 보낸 JSON을 자동 적용하는 기능이나 서버 전송은 없습니다.

원문에서재생성: `python tools/build_ocr_rule_review.py`. 템플릿은tools/templates/ocr-rule-review.html입니다. 원문72ID중복/누락은빌드시검사합니다.

## 검증

실제 Chromium에서72규칙+전체의견,빈내보내기차단,질문/수정동시입력,검색/단계/작성필터,숨겨진의견포함,JSON/텍스트원문보존,한글/줄바꿈/따옴표/HTML문자보존,실제클립보드쓰기·읽기,JSON다운로드,새로고침복원,내용지운항목제외를검사했습니다.390픽셀모바일폭가로넘침없음,데스크톱/모바일스크린샷시각확인. file://로직접열어입력·내보내기도확인했습니다.

저장/클립보드실패를강제한검사에서저장경고와수동전체선택대응을확인했습니다. 개발중문구수정에서발생한JS구문오류를수정하고최종파일로전체동작검사를다시통과했습니다. 시험입력은최종브라우저저장소에서비웠고파일에는포함되지않습니다. QA이미지/시험JSON은private/rule-review-ui081에만저장했습니다.

이번변경은검토UI뿐이며OCR규칙·최신076입력·075채점·Drive채점보고서를바꾸지않았습니다. 재OCR/재채점없음.
