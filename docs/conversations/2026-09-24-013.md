# 대화 — 객관식·주관식 모델 분리 제안

2026-09-24. 개별 발화 시각은 조회하지 않았습니다.

## user — 원문

1. 음 객관식이 완전한 성공한 것도 아니었다는거네.
2. 그럼 객관식인지 주관식인지 확인해서 객관식이면 숫자만 찾도록 설정된 모델을 불러와서 시키고

   주관식이면 그쪽에 맞게 학습된 모델 불러와서 채점하도록 하는거 어떤지?
3. 판단을 어떻게 할지는 이번대화 이후에 정해보자

## assistant — 진행 요약, 원문 아님

이전 객관식 성공은 사람이 영역을 지정한 조건의 숫자 판독 성공이며 자동 위치 추출까지 성공한 것은 아니라고 설명했습니다. 유형별 모델 분리는 설계 후보로 기록하되 유형 판단 방법은 이번에 정하지 않겠다고 안내했습니다.

## 설계 검토 요약 — 실제 구현 결과 아님

객관식은 선택 표기·숫자 인식, 주관식은 손글씨 문자·문장 인식으로 역할을 분리하는 방향을 제안했습니다. 다만 숫자만 출력하도록 제한하면 인쇄된 문항 번호·선지 번호·잡음까지 답으로 오인할 수 있으므로 답안 위치 추출 및 판독 보류가 별도로 필요합니다. 현재 객관식2번의 잘림은 숫자 모델 교체만으로 해결된다고 보장하지 않습니다. 복수 선택과 수정·취소 표기를 보존해야 합니다.

주관식 인식 모델은 학생이 쓴 내용을 읽고, 채점은 확인된 답지·허용 답 및 문항 조건과 비교하는 별도 단계로 둡니다. 사용자 요청에 따라 유형 판별 방법·분류기 선택은 미정으로 유지합니다. 모델 선택·학습·코딩·재시험은 이번에 수행하지 않았습니다. 작성 이후 최종 발화는 수록하지 않습니다.
