## 응답·처리 요약

앞선 main push와 원격 일치 확인을 안내했습니다. 두 조각은 학생 답 후보에서 분리됐지만 보고서 기본값 ‘전체’ 때문에 다시 표시된다고 설명했습니다. 사용자 요청에 따라 기본 화면을 ‘검토 대상 · 제외 숨김’으로 바꾸고 ‘전체’를 제거했습니다. 제외 144개는 별도 ‘제외 기록’에서만 보며 ‘답 후보에서 제외됨 · 과거 OCR’이라고 명시합니다. 기본 966개에는 학생 후보 및 혼합 검토 대상이 포함됩니다.

실제 브라우저에서 기본 966개, 제외 144개, 지정 두 ID의 기본 검색 결과 0개/제외 기록 검색 결과 각1개, 제외 문구, 페이지 이동을 확인했습니다. OCR 결과·채점·규칙은 변경하지 않았습니다. 이전 HTML은 private의 report-light-before-069.html로 보존했고 validation-069.json에 새 보고서 해시와 검사 범위를 기록했습니다.

기존 Drive 파일을 5,701,887바이트 HTML로 갱신했습니다. 코드·기록만 Git 대상이며 학생 자료는 private에 유지합니다. 최종 답변 이전에 확인된 발화 원문과 처리 요약만 기록합니다.
