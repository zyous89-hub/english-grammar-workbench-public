# 대화163 — 원본 스캔 해상도 자동확정 안전장치

## 사용자 요청

사용자는 지금까지의 설정·오류 0 검증이 A4 300dpi(2480×3507) 스캔 기준이며, Claude의 200dpi 시험에서 판독 변경 22조각·새 고신뢰 숫자 오독 3개가 있었다고 전달했습니다. 이는 사용자가 전달한 배경이며 이번 작업에서 그 수치를 재측정한 것은 아닙니다.

학생 원본 페이지의 짧은 변이 2400~2560px 범위 밖이면 해당 페이지의 모든 문항을 보류하고 아래 사유를 표시하도록 요청했습니다. 범위의 양 끝은 포함합니다. 판독 로직을 유지하고, 범위에 맞추려고 이미지를 확대·축소하지 않습니다.

`스캔 해상도 확인 필요: 300dpi로 스캔해 주세요 (현재 짧은 변 N px)`

## 구현

- `tools/scan_resolution.py`는 추출에 사용한 `source/sources/` 학생 원본 사본의 헤더를 읽습니다. 사본이 없는 기존 구조에서는 기록된 원본 경로를 사용합니다. 파일이 없거나 읽을 수 없으면 오류로 중단하며 자동확정을 허용하지 않습니다. DPI 메타데이터가 아니라 실제 픽셀 수 검사입니다.
- 새 입력 준비에서는 회색조 원본의 크기를 `pages.json`의 `scan_short_side`에 기록합니다. 기존 배치에는 이 필드가 없으므로 채점 시 실제 학생 원본 사본에서 측정합니다. 1334×1888 정렬용 비교 이미지나 답 조각을 측정하지 않습니다.
- 공통 `question_review`에 1단계·사유17·`scan_resolution` 보류를 추가했습니다. 원래 후보·판독·기존 보류 사유를 보존하고 최종 자동 선택만 막습니다. 이미 보류된 문항과 조각이 없는 문항에도 해당 페이지의 사유를 추가합니다.
- 두 정책의 공통 페이지 로딩과 구형 `grade_added_ink` 경로에도 연결했습니다. 결과 파일은 엔진의 정확한 사유 문구를 전달하며, 구형 보고서도 사유를 표시합니다.
- 기존 OCR·정렬·리사이즈·재판독 수식, 0.8·70%, A·B, F05~F12·F06(re-read)·답지 개수 검사는 그대로입니다. 원본을 검사 범위에 맞추는 새 보정은 없습니다.

## 검증

162의 OCR·문항 소속을 재사용했습니다. 새 OCR 0회·새 소속 배정 0회이며, 200dpi의 OCR 정확도를 다시 측정한 실험은 아닙니다. 기존 후보를 그대로 둔 상태에서도 해상도 안전장치가 모든 자동확정을 막는지 검증했습니다.

| 입력 | 정책 | 자동확정 | 보류 | 전사와 다른 자동확정 |
|---|---|---:|---:|---:|
| 정상 18쪽, 짧은 변 모두 2480px | 사용자안 | 22 | 112 | 0 |
| 정상 18쪽, 짧은 변 모두 2480px | 보조 제안안 | 20 | 114 | 0 |
| 2쪽만 1654px 사본으로 교체 | 사용자안 | 21 | 113 | 0 |
| 2쪽만 1654px 사본으로 교체 | 보조 제안안 | 19 | 115 | 0 |

정상 데이터는 양안 134문항의 `review` 객체와 전사 비교 결과가 162와 완전히 같습니다. 자동확정 목록·후보·답·판정·모든 보류 사유가 같으며 내보낸 결과의 표시 값도 동일합니다.

저해상도 시험 사본은 기존 2쪽을 1654×2339px로 줄여 별도 폴더에 만들었습니다. 원본은 수정하지 않았습니다. 양안 모두 2쪽 11문항 전체가 보류되고, 모든 문항에 `스캔 해상도 확인 필요: 300dpi로 스캔해 주세요 (현재 짧은 변 1654 px)`가 추가됐습니다. 기존 보류 10개와 자동확정 1개를 모두 포함합니다. 다른 123문항은 판정·후보·사유가 완전히 같습니다.

단위테스트 1개를 추가해 전체 70개 검사 통과. 추가 테스트의 하위 사례는 1654/2399/2400/2480/2560/2561px, 가로·세로 방향, 정상 객체 완전 동일, 확정 가능·기존 보류·조각 없음, 원본 사본 우선과 오래된 크기 기록 재측정, 파일/크기 불변 및 없는 원본의 중단입니다.

브라우저에서 저해상도 11문항을 각각 열어 자동 보류와 정확한 사유 표시를 확인했습니다. 390px 폭에서 페이지 가로 넘침도 없습니다. 원자료·기존 전사·162 결과·소속·교사 수정 파일 해시를 보존했습니다. 독립 코드 감사에서 누락된 실제 채점 경로나 판독 변경을 발견하지 않았습니다.
