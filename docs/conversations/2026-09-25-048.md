# 대화048 — 잡음 후보 제거로 보류율 낮추기

2026-09-25. 사용자 발화와 확인 결과의 요약이며 개별 시각은 확인하지 않았습니다.

사용자는 한자 출력을 단순히 정답 선택에서 제외하자는 뜻이 아니라, 잡음에서 나온 인식을 답 후보 간 이견으로 세지 않도록 보류 메커니즘을 조정하려는 것이라고 정정했습니다. 여러 추출 결과 중 실제 답이 아닌 결과를 순차적으로 제거하고자 하며 한자 결과가 쉬운 시작점이라는 설명입니다.

첨부 화면에 대응하는 실제 실행 데이터를 확인했습니다. 네 후보의 점수가 모두 기존0.8 미만이므로 해당 사례는 후보 간 충돌이 아니라 자격을 갖춘 숫자 후보가0개라서 자동 보류된 경우입니다. 현재 보고서가 두 원인을 하나의 공통 문구로 표시하여 원인을 구분하기 어렵게 만든 점을 확인했습니다. 네 행은 같은 이미지를 독립적으로 네 번 읽은 것이 아니라 서로 다른 추출 영역의 OCR 결과입니다.

응답 방향: 후보 자격 검사 → 유효 후보 간 비교 → 남은 답 후보의 확정 조건을 분리합니다. 한자 전용 잡음, 종이 배경 조각, 인쇄 잔여물·선 조각은 근거를 갖춰 경쟁 후보에서 제외하는 방향이 사용자 의도입니다. 원출력 보존 여부와 의사결정 참여 여부는 구분합니다. 숫자처럼 인식된 잡음은 문자 종류만으로 제거되지 않으며 영역의 내용·원본과의 차이 등을 확인해야 합니다. 한 후보만 남았다는 사실만으로 숫자 판독이 정확하다고 확정하지 않습니다.

기존0.8 경계를 유지하면 첨부의 최고 점수 후보도 여전히 자동 확정되지 않습니다. 잡음 제거와 낮은 OCR 점수 후보를 다른 표시 근거로 확정하는 조건은 별도 설계·검증 항목입니다. 이번에는 사례 조회와 원인 확인만 했으며 OCR 재실행·기존 판정·점수 변경은 하지 않았습니다.
