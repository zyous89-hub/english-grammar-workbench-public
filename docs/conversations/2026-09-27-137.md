# 대화137 — 다른 컴퓨터에서 검증 화면 열기

2026-09-27. 사용자 발화 원문: “안열림”. 다른 컴퓨터에서 보는지 묻자 “ㅇㅇ”이라고 답했습니다.

앞선 `127.0.0.1:8141` 링크는 실행 중인 PC에서만 유효했습니다. 실제 서버 응답은200·134문항으로 확인했지만 다른 PC에 전달할 주소가 아니었습니다. Codex 탭 열기 요청은 대기됐으며, 기본 브라우저 실행 명령은 정책으로 차단됐습니다.

## 조치와 확인

- 기존 검증 화면을 재사용하고 입력·저장 전달 방식만 분리했습니다. `tools/package_result_review.py`, `src/result-portable.js`로 결과·사진이 포함된 HTML을 생성합니다. 사유 목록이나 채점 규칙은 추가하지 않았습니다.
- 다른 PC용 HTML은 서버 없이 표시합니다. 교사 수정은 `teacher-corrections.json` 다운로드로 보관하고 다시 불러옵니다. HTML 자체에 저장되지 않는다는 점을 화면에 명시했습니다. 다른 제출·잘못된 형식은 적용하지 않습니다.
- 실제 사용자안134문항·고유 근거1104파일, 34,634,153바이트입니다. 결과·전사·이미지 입력은 변경하지 않았으며 새로운 OCR·재채점은 없습니다.
- 전체41개 검사 통과. 합성 자료에서 원본 이미지 바이트 포함·스크립트 문자열 안전 처리·입력 수정 파일 보존을 검사했습니다.
- 브라우저에 HTML을 로드한 뒤 네트워크를 끊었습니다. 실제134문항 목록·사진이 표시됐고 오류·경고0건이었습니다. 합성 자료에서 교사 수정 JSON 다운로드 후 페이지를 다시 열어 오프라인으로 불러왔으며 `정답 · 2,3`과 차이 표시를 확인했습니다.
- 자동화 도구의 `file:` 접근 제한 때문에 브라우저 검사는 정적 로컬 서버에서 초기 문서를 로드한 뒤 오프라인으로 수행했습니다. 사용자의 다른 PC에서 직접 실행한 검증은 아닙니다.
