# 대화112 — 저작권 자료 저장소 제외

사용자가 시험지 저작권 자료의 저장소 포함 문제를 제기한 뒤 “음......... 미리 정리좀 해놓자”라고 요청했습니다. 직전 안내에서 로컬 자료 보존·Git 추적 제외·과거 커밋 정리를 설명했습니다.

학생의 사용 동의와 출판사 자료의 배포 권한은 별개입니다. 대화098의 저장소 포함 예외를 철회하고 `data/ocr-review-C/` 전체를 로컬 전용으로 전환합니다. 폴더의 원본 PDF, 학생 스캔 18장, 전사, 메타데이터, 동의 증빙을 Git 추적 및 과거 이력에서 제외합니다. 기존 경로의 실제 파일은 보존합니다. 추가 시험의 답지1·답지2는 원래 Git에 포함되지 않았습니다.

`.gitignore`에 해당 폴더와 브라우저 임시 산출물 폴더를 추가했습니다. 자료가 들어 있던 옛 커밋을 다시 병합하거나 푸시하지 않습니다. 다른 작업에서 옛 커밋 ID를 참조할 때는 이번 이력 정리로 ID가 바뀌었음을 고려해야 합니다. 독립 복제본에서는 필요한 작업만 새 이력에 옮겨야 합니다.

과거 이력 변환은 별도 미러에서 수행하고 로컬 자료 및 진행 중인 작업 파일의 해시를 전후 확인합니다. 복구용 이력 번들은 Git에서 제외된 `private/history-cleanup112/`에 로컬 보관합니다. 복구용 번들에는 삭제 전 자료가 남으므로 업로드하지 않습니다. GitHub의 캐시·이미 존재하는 다른 복제본의 삭제까지 보장하는 작업은 아닙니다. 저장소 공개 범위는 비공개로 유지합니다.

완료 검증: 정리된 main을 원격의 예상 커밋이 바뀌지 않았음을 확인하는 force-with-lease로 반영했고 원격 SHA를 재조회했습니다. 로컬·정리 미러의 모든 참조에서 도달 가능한 이력에 자료 폴더 경로가 0개임을 확인했습니다. 원격 브랜치는 main 하나이며 태그는 없었습니다. 최신 파일 트리는 정리 전후 동일하고 로컬 자료 25개와 다른 작업의 파일 4개, 총 29개 SHA256가 불변입니다. 진행 중인 작업의 미커밋 상태도 유지했습니다. 저장소 비공개 및 ignore 적용을 확인했습니다. 상세 검증은 로컬 `private/history-cleanup112/verification.json`에 있습니다. 과거 문서에 쓰인 짧은 커밋 ID와 업로드 완료 표현은 당시 기록이며 현재 자료 포함 상태를 뜻하지 않습니다.
