# 대화142 — 인식 결과 없음 조각 모음

2026-09-27. 앞서 사용자는 보류 사유를 대화에 나열하도록 요청했고, assistant는 141 결과에서 문항별 중복 집계한 사유 8종을 안내했습니다. ‘OCR 실행 후 인식 결과 없음’은 양안 각각 59문항이었습니다.

사용자 원문:

> OCR 인식 결과 없음 59개
> 이미지 파일 모아서 순서대로 볼 수 있는 html 작성
> 양측 안 모두거

## 결과

141 양안의 최종 보류 문항 중 사유 코드 5의 `crop_ids`만 모았습니다. 두 안 모두 같은 59문항·91개 조각이며 문항 전체가 무응답이라는 뜻은 아닙니다. 쪽수·문항·조각 번호 순서로 표시합니다. 사용자안/제안안 전환, 이전/다음 문항, 직접 문항 선택, 좌우 방향키, 조각 확대와 원래 학생 문항 사진을 넣었습니다. 현재 안의 다른 보류 사유도 함께 표시합니다. OCR·채점 변경은 없습니다.

- [HTML 생성 도구](../../tools/package_no_read_gallery.py), [최소 회귀 검사](../../tests/test_no_read_gallery.py).
- 실행: `private/paddle-env/Scripts/python.exe tools/package_no_read_gallery.py private/two-policy-regrade141 private/OCR-no-read142-portable.html`.
- 출력: `private/OCR-no-read142-portable.html`, 15,696,998바이트. 고유 사진 150장(원래 문항 59장 + 해당 OCR 조각 91장)을 한 번씩 내장했습니다.
- [다른 PC용 HTML]((비공개 기록)). 다운로드 후 브라우저에서 엽니다. 업로드 후 크기·소유자만 접근 권한을 재확인했습니다.
- 실제 브라우저에서 오프라인으로 두 안 각각 59문항을 모두 순회해 91개 조각과 문항 사진의 이미지 디코딩 성공을 확인했습니다. 확대·이전/다음 이동·390px 화면 넘침 없음·실행 중 JS 오류 없음 확인. 모바일 화면도 직접 검토했습니다.
- 합성 자료 회귀 검사 1개 통과: 다른 사유 제외, 숫자 순서, 사진 중복 저장 방지, 문구 안전 인코딩, 기존 출력 덮어쓰기 거부. 전체 채점 엔진은 바꾸지 않았습니다.
