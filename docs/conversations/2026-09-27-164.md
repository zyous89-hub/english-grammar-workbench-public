# 대화164 — 4960px 확대 사본의 해상도 안전장치 확인

## 사용자 요청

사용자는 대화163의 해상도 검사를 채택한 뒤 다음 추가 확인을 요청했습니다.

> 해상도 검사: 기존 페이지 하나를 짧은 변 4960px(600dpi)로 키운 사본도 그 페이지 전 문항 보류 + 사유 표시되는지 확인

## 결과

기존 2쪽의 2480×3507px 학생 스캔을 별도 시험 폴더에 4960×7014px로 확대했습니다. 실제 스캐너로 새로 만든 600dpi 자료는 아니며, 요청한 픽셀 크기의 사본입니다. 원본과 판독 코드는 변경하지 않았습니다.

- 사용자안과 보조 제안안 모두 해당 페이지의 **11문항 전체가 보류**됐습니다.
- 11문항 모두 `스캔 해상도 확인 필요: 300dpi로 스캔해 주세요 (현재 짧은 변 4960 px)`가 추가됐습니다. 기존 보류 사유와 후보는 유지됐습니다.
- 다른 123문항의 후보·판정·보류 사유는 162 비교 기준과 완전히 같습니다. 전체 자동확정/보류는 사용자안 21/113, 보조 제안안 19/115입니다.
- 결과 파일 형식 검사와 실제 브라우저의 11문항 보류·정확한 사유 표시를 확인했습니다. 390px 화면에서도 가로 넘침이 없습니다.
- 원자료·전사·기존 결과·교사 수정 파일의 해시를 보존했습니다. 독립 읽기 전용 감사에서도 두 정책의 사유 전달 경로에 결함을 발견하지 않았습니다.

162의 고정 OCR·소속을 재사용해 새 OCR 0회, 새 소속 배정 0회로 검사했습니다. 600dpi OCR 정확도를 측정한 시험이 아닙니다. 코드 변경이 없어 기존 70개 테스트는 이번에 재실행하지 않았습니다. 대화163에서 확인한 전체 통과 기록은 그대로입니다.
