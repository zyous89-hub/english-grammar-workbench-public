# 대화083 — 검토 HTML 갱신과 띄어쓰기 정리

사용자 원문: “html새로줘봐 그리고 띄어쓰기좀 잘해봐줄래?”

72개 규칙과 출처 설명을 문장 단위로 다시 쓰고 띄어쓰기를 정리했습니다. 검토본 083 (비공개 기록)에 A01~A10 답변, A02·G01 직접 입력 경로 변경, A01의 남은 매핑 제한과 A06의 미변경 상태를 표시했습니다. 기본 ocr-rule-review.html도 같은 내용으로 갱신했습니다. 원래 079 감사 문서는 보존했습니다.

입력과 복사 기능은 유지합니다. 새 의견의 JSON/텍스트에는 목록 083, 원문 해시, 앞선 답변을 포함합니다. 접근 가능한 이전 브라우저 저장값이 있으면 새 저장키로 옮깁니다. 파일 위치나 브라우저가 다르면 이전 임시 저장값을 읽지 못할 수 있습니다.

Chromium에서 72개 규칙, 답변 표시, A02 새 문장, 질문과 수정 요청, JSON/텍스트 내보내기, 새로고침 유지, 모바일 가로 넘침 없음, HTML 파일 직접 열기를 확인했습니다. 데스크톱 화면도 직접 확인했습니다. 검사 입력은 비웠습니다. OCR 규칙 변경이나 재채점은 이번 작업에 포함되지 않습니다.
