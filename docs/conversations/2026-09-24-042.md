# 대화 — 학생 성적이 아닌 OCR 자체 검수

2026-09-24. 확인 가능한 사용자 발화 원문과 assistant 진행 요약입니다. 개별 발화 시각은 확인하지 않아 만들지 않습니다. 최종 응답 전 작성했습니다.

1. 사용자 원문: “너가 OCR을 채점해오는거야”
2. assistant 응답 요약: 학생 숙제 성적이 아니라 OCR 인식·채점이 맞았는지 평가하라는 뜻임을 확인하고, 앞선 보고의 중심을 잘못 잡았다고 정정했습니다.
3. 사용자 원문: “ㅇㅋ OCR 체크해와봐”
4. assistant 진행 요약: 실제 OCR 입력 이미지와 출력을 대조하고, 글자 오류와 추출·문항 연결 오류를 분리해 점수 내림차순으로 정리한다고 안내했습니다.
5. assistant 진행 요약: 높은 점수에서도 숫자 누락 및 다른 문항 연결 오류가 있으며, 애매하거나 잘린 필기는 별도 확인으로 남긴다고 설명했습니다.
6. assistant 진행 요약: 입력 조각 1,015개를 직접 대조했고, 문항에 문제가 있다는 이유만으로 정상 인식 조각을 오류 처리하지 않도록 보고서를 수정했다고 안내했습니다.

실제 검수와 제한은 OCR 조각별 육안 검수 (비공개 기록)에 분리했습니다. 상세 필기·이미지·전사는 로컬 전용입니다.
