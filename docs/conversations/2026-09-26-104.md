# 대화104 — 숫자가 아닌 기호의 제외 사유

사용자 요청 원문:

> 인식했는데 기호로 보이는 경우 (체크 표시, 지움 표시 등)를 판별해서 숫자가 아니어서 제외됨
> 이라는 이유를 만들자

사용자 지정 사유: **숫자가 아닌 기호로 판별되어 제외됨**.

103의 답 존재 확인 뒤, 발견한 개별 표시를 판별할 때 적용합니다. 여기서 제외는 숫자 답 후보에서의 제외입니다. 원본 이미지·인식 원문·표시 위치와 판별 근거는 남깁니다. 체크·지움 표시는 선택이나 취소의 의미가 있을 수 있으므로 문항 전체의 무응답이나 무의미한 흔적으로 확정하지 않습니다.

상태 구분:

- 기호로 판별됨: 위 제외 사유를 기록하고, 확인된 종류가 있으면 체크 표시·지움 표시 등으로 함께 표시합니다.
- 숫자인지 기호인지 불확실함: `숫자·기호 구분 불확실`로 남깁니다. 예를 들어 OCR이 선을 `1`로 출력하거나 체크를 문자로 출력할 수 있으므로 출력 문자열만으로 기호 여부를 확정하지 않습니다.
- 숫자와 기호가 함께 있음: 기호가 포함됐다는 이유로 숫자까지 전부 제외하지 않습니다. 분리 가능한 근거가 없으면 혼합 표시 검토 대상으로 남깁니다. 취소선이 있는 숫자의 유효성도 별도 판별이 필요합니다.

규칙과 표시 문구를 추가한 단계입니다. 자동 기호 판별기는 이번에 구현하지 않았으며, 실행 중인 실험 코드·입력·결과는 변경하지 않았습니다. 기존 `eligible_answer`의 문자 형식 검사만으로 체크·지움 표시가 확인됐다고 기록해서는 안 됩니다.
