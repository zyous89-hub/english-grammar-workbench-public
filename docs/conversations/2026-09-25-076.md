tools/extract_added_ink.py에서 원본 PDF 문자 좌표 수집과 픽셀 보존에 공통 PRESERVED_CHOICE_SYMBOLS를 사용합니다. 기존①~⑤와 동그라미 소문자ⓐ~ⓩ(U+24D0..U+24E9)를 보존합니다. 일반 a~z, 대문자Ⓐ~Ⓩ,⑥ 등은 이번 범위가 아닙니다. 글자 좌표+3픽셀 복원과 기존 선택 표시 검토 분리는 유지합니다. 특정 문항 ID 분기나 답지 전사 보정은 없습니다. 다음 채점 보고서에는 실제 보존 영문이 있을 때①~⑤·ⓐ~ⓩ 적용을 안내합니다.
