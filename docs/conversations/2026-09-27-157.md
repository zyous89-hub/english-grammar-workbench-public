# 대화157 — 새 재판독 조건의 대상 수 집계

2026-09-27 사용자 원문:

> 총 몇개의 조각이 재채점 대상이 되는지?

## 확인 결과

최신 실행153의 물리 조각 1,053개를 기준으로 154~156의 제안 조건을 읽기 전용으로 집계했습니다. 새 OCR·채점·엔진 수정은 하지 않았습니다. 현재 일반 필기 경로 469개를 대상으로 하며, 보호된 인쇄 선택 표시 449개와 추출 후 제외 135개는 기존대로 제외했습니다.

| 재시도 이력의 해석 | 사용자안 | 제안안 | 두 안 중복 제거 |
| --- | ---: | ---: | ---: |
| 기존 코드처럼 검사 이력도 전부 제외 | 87 | 89 | **89** |
| 실제 추가 OCR 이력만 제외하는 경우 | 448 | 450 | **450** |

기존 `circle_search` 이력은 370개에 있습니다. 그중 5개만 추가 OCR을 실행했고, 나머지 365개는 기하 검사만 했습니다(`attempts: 0`). 사용자 요구는 ‘재시도 이력이 있으면 금지’이며, 이번 집계가 그 정의를 실제 OCR만으로 변경한 것은 아닙니다. 현재 guard를 유지할 때는 89개, 실제 추가 OCR만 이력으로 정의할 경우 450개라는 조건부 차이입니다.

## 집계 기준과 한계

- 두 안의 보류 문항에 연결된 조각 또는 낮은 신뢰도 조각을 크기 변경 후보로 세었습니다. 여러 문항에 연결된 같은 조각과 여러 분기에 걸린 조각은 물리 ID로 한 번만 셌습니다.
- 실제 처리 PNG에서 기존 흰 테두리 10픽셀을 뺀 뒤, 현재 재판독 코드와 같은 `<255` 필기 마스크의 높이를 채점용 좌표로 환산했습니다. 추출 당시의 외접 사각형 높이를 실제 필기 높이로 대신하지 않았습니다.
- 실제 추가 OCR만 제외할 때 높이 8픽셀 초과 크기 변경 후보는 사용자안 445개, 제안안 447개입니다. 8픽셀 제한은 크기 변경에만 적용하므로 작은 선 3개를 추가하면 448/450개입니다. 해당 선은 `C-04-ink0046`의 `_`, `C-05-ink0023`의 `−`, `C-13-ink0015`의 낮은 점수 `1`입니다. 유니코드 마이너스도 선으로 포함했습니다.
- `0`과 기존 기하 검사에서 발견한 도형 조건은 이 자료에서 위 후보 집합 밖에 추가 조각을 만들지 않았습니다. 높이 제한에 걸린 작은 일반 필기 10개도 기존 도형 검사에서는 도형 검출이 없었습니다. 새 선 연결 알고리즘의 결과를 예측한 것은 아닙니다.
- 89/450은 처리 후보 수입니다. 주변 연결·테두리 제거·내부 획 확인에 따라 실제 추가 OCR 횟수는 달라질 수 있습니다. 답지나 확인 전사를 대상 선정에 사용하지 않았습니다.
