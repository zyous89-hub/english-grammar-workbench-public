# 대화066 — HTML 열기 시 멈춤 대응

사용자 원문: “html 열면 컴퓨터가 멈추는데 해결법?”

기존 보고서43,310,914바이트에 후보 이미지가 중복 삽입되고 문항 문맥 이미지도 함께 포함된 구조를 확인했습니다. 사용자 PC의 멈춤 원인을 직접 측정한 것은 아니지만 과도한 이미지/문서 부하를 줄이도록 수정했습니다.

가벼운 보기5,703,078바이트를 만들었습니다. 후보1110개 이미지를 각각 한 번만 데이터로 보관하고 화면에는20개씩 생성합니다. 확대는 클릭 시1개만 추가하고 닫으면 제거합니다. 문항 전체 문맥 이미지는 기존 원본 보고서에 보존합니다. 새 보기에는 후보 이미지·인식 내용·점수, 문항 판정·선택·답지, 검색·점수순·배경 제외 필터를 제공합니다. OCR 재실행이나 결과 변경은 없습니다.

후보1110개 및 제외100개 수, 이미지 원본 바이트 일치, 모의 DOM에서 페이지 전환·검색·필터·확대/닫기를 검사했습니다. 실제 브라우저 렌더링 및 사용자 PC 멈춤 해소 여부는 미검증입니다.

기존 Drive 파일 ID를 유지해 가벼운 보기로 교체하고 파일명·크기·부모 폴더를 재조회했습니다. 학생 데이터와 생성기는 private에, 변경 기록만 Git에 보관합니다.
