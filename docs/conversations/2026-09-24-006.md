# 대화 — 판독 수준과 오답 보존

2026-09-24. 아래 사용자·진행 발화는 원문이며 개별 시각은 조회하지 않았습니다. 내부 추론·도구 출력·작성 이후 최종 응답은 수록하지 않았습니다.

## user

너를 쓰겠다는건 아니었고 너랑 같은 수준까지는 뽑아야해서 물어본거야 일단 ㅇㅋ

너무 못쓴 글씨를 읽게하려다가 오답을 정답으로 만드는게 더 위험할거같아

## assistant — 진행 발화

이해했습니다. 목표는 로컬 프로그램의 판독 수준을 높이는 것이고, 그 과정에서 학생의 오답을 정답으로 바꾸면 안 된다는 뜻입니다. **애매한 글씨는 추측해서 확정하지 않고 확인 대상으로 남긴다**는 원칙을 기록하겠습니다.

사용자 원문의 행 끝 공백 한 곳은 제거했습니다.

## user — 판정 우선순위 구체화

오답-오답 정상
정답-정답 정상
정답-오답 나쁘지만 괜찮 - 궁극적으로 없애는게 목표
오답-정답 절대 일어나면 안됨

## assistant — 진행 발화 원문

이 네 가지를 채점의 우선순위로 기록하겠습니다. 특히 **오답을 정답으로 판정하는 것은 허용하지 않는 요구사항**으로 두고, 판단이 불확실한 답은 정답으로 확정하지 않는 방향으로 설계하겠습니다.
