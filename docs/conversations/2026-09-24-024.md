# 대화 — 객관식 채점 규격 초안

2026-09-24. 발화별 시각 미조회.

## user — 원문

객관식 채점 규격 정해보자

## assistant — 진행 설명 요약

원본 선지·학생 표시·답지 비교를 기준으로 규격을 작성하며 오답→정답 방지를 중심으로 사용자 확정 사항과 판단이 필요한 항목을 구분한다고 안내했습니다.

## 사용자에게 제시한 질문

- 정답이 ②·④인데 학생이 ②만 선택한 복수 선택 문항: 전체 일치만 정답으로 할지, 교재의 부분점수 기준을 적용할지.
- 하나만 고르는 문항에서 최종 답 2개가 명확한 경우: 복수 응답 오답으로 할지, 교사 확인 후 처리할지. 수정 여부가 애매한 사례는 별도 보류.

작성 시점에는 답변 대기 상태입니다.

## 후속 user — 질문 답변 원문

복수 선택 정책 질문: 점수를 매기는건 원하지 않음

단일 선택 복수 응답 질문: 복수 응답으로 기록하고 오답 처리 (추천)

## 후속 반영

점수·배점·부분점수 계산을 제외하고 단일 선택의 명백한 복수 응답은 오답으로 확정했습니다. 나머지 판독·채점 규칙은 초안 상태를 유지했습니다. 실제 채점은 수행하지 않았습니다.

## 실제 작업

[객관식 채점 규격](../multiple-choice-grading-spec.md) 초안을 작성하고 청사진·근거 목록에 연결했습니다. 사용자 원칙·assistant 제안·답변 대기를 구분했습니다. 실제 인식 코드 변경·모델 학습·학생 자료 채점은 하지 않았습니다. 작성 이후 최종 발화는 포함하지 않습니다.
