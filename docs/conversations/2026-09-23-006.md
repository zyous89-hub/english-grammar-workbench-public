# 대화 006 — 채점 프로그램의 M1·M2

- 날짜: 2026-09-23 (Asia/Seoul). 발화별 시각은 미확인입니다.
- 아래 사용자 요청과 진행 알림은 원문입니다. 역할·번호만 추가했습니다.
- 마지막 완료 응답은 아직 발화 전이므로 수록하지 않습니다. 도구 출력·내부 추론·인증정보는 제외합니다.

## 001 — user

일단 뭘 만들지에 대해서 완성해보자

1. 채점을 대신해주는 프로그램이야 - 실제 한세트(학생 한명의 1회분 숙제)를 채점하는데 얼마나 시간이 드는지 나중에 명확하게 알려줄게(기억해놔)
2. 나는 우리가 만들 프로그램에 폴더1(학생의 숙제를 스캔한것), 폴더2(학생에게 내준 숙제의 답지)를 제공할 거야
3. 그럼 그 프로그램은 다양한 목표를 성취하면 됨.
4. 첫번째 목표(M1)은 외부 프로그램 없이 폴더1의 파일을 폴더2를 기준으로 채점하고 기록을 남기는 것이야
5. 두번째 목표(M2)는 외부 프로그램없이 학생이 틀린 어법을 구분해서 추가 기록을 남기는 것.

일단 여기까지가 목표야.

## 002 — assistant (진행 알림)

목표를 **학생 숙제 채점 프로그램**으로 다시 정리하겠습니다. 폴더1의 스캔 숙제를 폴더2의 답지로 채점·기록하는 것을 M1, 틀린 문항의 어법을 구분해 추가 기록하는 것을 M2로 두겠습니다.

**학생 한 명의 1회분 숙제를 ‘한 세트’로 정의하고, 현재 수동 채점에 걸리는 시간은 나중에 알려주실 예정**이라는 점도 프로젝트 문서와 기억에 남기겠습니다.

## 003 — assistant (진행 알림)

이제 프로젝트의 우선 목표를 **M1 채점·기록 → M2 오답 어법 기록**으로 바꿔 문서에 반영했습니다. 기존의 HTML 제작 중심 설명과 스캔 처리 제외 계획도 최신 목표와 구분해 두었습니다.

채점 시간은 ‘추후 제공’으로 남겼고, 파일 형식·기록 양식·인식 방법은 아직 확정하지 않았습니다. 이번에는 목표만 정리하며 구현을 시작하지 않습니다.
