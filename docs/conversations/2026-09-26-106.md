# 대화106 — 신뢰도 부족과 보류 사유의 누락 점검

사용자 요청 원문:

> 다음으로 신뢰도 부족(기존에 있던거)을 넣어보자
> 이러면 지금 나온 보류의 전체를 세분화했나 체크해봐

확정 추가 사유: **신뢰도 부족 — OCR 점수 0.8 미만**. 기존 경계를 유지합니다. 정확히 0.8이면 이 조건에는 해당하지 않습니다. 이 점수는 정답일 확률이 아니며, 낮은 점수여도 올바른 전사일 수 있습니다. 점수가 없으면 점수 미산출/인식 미실행으로 구별해야 합니다. 현행 채점은 None을 0으로 전달하지만 이는 낮은 점수를 실제로 측정했다는 뜻이 아닙니다.

## 코드 경로 점검 결과

아직 전체를 세분화한 것은 아닙니다. `grade_added_ink.grade`의 보류 조건은 (1) 선택 결과 없음 또는 (2) 답지 해석 실패입니다. 선택 결과가 없는 경우는 후보 집합 없음, 서로 다른 후보 집합, 의미 주석 존재로 나뉩니다. 후보가 없는 세부 이유는 `eligible_answer`의 경로 제한, 점수 조건, 문자 형식 조건, 유효 번호 없음으로 나뉩니다.

| 원인 | 지금까지 정한 규칙과의 관계 |
|---|---|
| 실제 답 없음 | 103의 빈칸 확인 대상. 현재 빈 조각만으로 확정 불가. 무응답 채점 정책 미정. |
| 기호로 확인됨 | 104의 숫자가 아닌 기호 제외. 문자 형식 탈락만으로 기호라고 확정 불가. |
| OCR 점수 0.8 미만 | 이번에 사유 추가. |
| 여러 번호가 있음 | 105에서 허용. 그 자체는 보류 사유가 아님. |
| OCR 출력 없음/점수 없음 | 추가 구분 필요. 답 없음과 다른 상태. OCR 실행 여부도 함께 기록. |
| 답 형식 해석 불가 | 추가 구분 필요. 문자·물음표 혼합, 범위 밖 번호 등. 전부 체크·지움 표시로 분류하면 안 됨. |
| 후보에서 제외된 경로 | 추가 구분 필요. `choice_mark_review`는 선택 표시 미해석, `excluded_after_extraction`은 원본/배경/빈 조각 등 기존 제외 근거를 기록. 인쇄 번호 보존은 학생 선택 확인이 아님. |
| 서로 다른 답 후보 | 추가 구분 필요. 복수 답의 분리 조각인지, 실제 충돌인지 아직 구별하지 못하는 경우 포함. |
| 모름 등 의미 주석 | 추가 구분 필요. 숫자 필기와 함께 존재할 수도 있으므로 근거를 모두 보존. 최종 채점 정책 미정. |
| 답지 해석 실패 | 추가 구분 필요. 학생 OCR 문제와 분리. |

과거 재평가 경로 `review_ocr_reference.replay`에는 `held_candidates`가 선택을 막는 조건도 있습니다. 숫자 형식·점수를 통과했지만 원본/배경/정렬 경로 등으로 보류된 조각입니다. 위의 경로 제한 항목에 대응합니다. 현재 `grade_added_ink`는 이 조건이 동일하지 않으므로 같은 보류 로직으로 설명하지 않습니다.

정렬 실패·파일 누락·해시 불일치 등으로 실행 자체가 중단된 경우는 문항 보류가 아니라 처리 실패입니다. 별도 상태로 남겨야 합니다.

## 기록 원칙

개별 조각의 제외 사유와 문항 전체의 보류 사유를 구분합니다. 한 조각이 기호나 낮은 점수여도 다른 근거로 문항 답이 확정될 수 있습니다. 한 문항에 여러 원인이 함께 있으면 사유를 여러 개 기록하며 하나로 덮어쓰지 않습니다.

이번 점검은 현재 코드 분기의 누락 여부 점검입니다. 실행 중인 시험 결과를 읽어 문항별 보류 건수나 실제 원인을 재분류한 작업은 아닙니다. 규칙 문서만 추가했으며 테스트 코드·입력·결과·평가 기준은 변경하지 않았습니다.
