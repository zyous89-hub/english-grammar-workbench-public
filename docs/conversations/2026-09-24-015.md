# 대화 — 유형 판단 세 후보의 비용과 데이터 처리

2026-09-24. 개별 시각 미조회.

## user — 원문

3가지 안이 있어
1번 후보 - 그냥 ChatGPT, Claude 같은 외부 AI를 API로 넣기
2번 후보 - Jev같은 판단형 AI를 API로 넣기
3번 후보 - 직접 만들기

비용 판단, 보안상 문제, 내용 유출 측면에서 판단해봐

## 후속 확인

assistant가 Jev의 정확한 서비스를 확인 요청했고 사용자가 https://en.wikipedia.org/wiki/Jev_(AI_model) 링크를 제공했습니다. Wikipedia로 대상을 확인한 뒤 TypeSafe공식 문서·정책을 비교 근거로 사용했습니다.

## assistant — 진행 요약, 원문 아님

첫쪽 유형 분류 비용을 기준으로 공식 문서를 조사하고 외부 전송·보관·학습 사용을 구분하겠다고 안내했습니다. Jev단가가 비교 소형LLM보다 낮지만 외부API인 점은 같고, 학생 필기 대신 문제 원본의 최소 단서만 보내는 설계가 가능하다고 설명했습니다.

## 실제 작업

[세 후보 비교](../type-classifier-options.md)에 가격 산술 예시·데이터 정책·개발비 및 프로젝트 권고를 기록했습니다. 실제 API연결·학생 자료 전송·성능 시험·방향 확정은 하지 않았습니다. 작성 이후 최종 발화는 수록하지 않습니다.
