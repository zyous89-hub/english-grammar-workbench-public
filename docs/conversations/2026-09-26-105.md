# 대화105 — 복수 답 허용

사용자 요청 원문:

> 복수 정답이라 고민하다가 포기!!하는 경우가 있으니까
> 복수 정답이 가능하다는걸 넣자 - 이거 지금 작업중인거에 안섞이게 유의해줘!!

확정 규칙: **한 문항에 여러 번호로 된 답이 가능하다. 복수라는 이유만으로 인식·답 선택을 포기하거나 보류하지 않는다.**

학생이 쓴 답의 추출과 교재 정답 대조는 구분합니다. 예를 들어 학생이 `2,3`을 썼다면 둘 다 학생 답 후보로 보존합니다. 실제 정답 여부는 답 추출 뒤 교재 답과 별도로 대조합니다. 교재 답에 맞춰 학생 답을 하나만 고르거나 수정하지 않습니다.

- 한 답 영역에 여러 번호가 명확히 쓰여 있으면 복수 답으로 처리합니다.
- 번호들이 별도 조각으로 나뉘었더라도, 분리됐다는 이유만으로 복수 답을 거부하지 않습니다. 같은 답의 서로 다른 번호인지 확인하는 과정은 필요합니다.
- 서로 다른 OCR 해석 후보, 중복 조각, 취소한 번호를 무조건 합쳐 복수 답으로 만들지는 않습니다. 이 경우 보류 사유는 복수 답 자체가 아니라 해당 불확실성입니다.

격리 범위: 이번 변경은 이 문서 한 파일뿐입니다. 실행 중인 101의 코드·입력·평가 기준·결과에 적용하지 않았습니다. 자동 판별·결합 로직의 구현과 검증은 별도 후속 작업입니다.
