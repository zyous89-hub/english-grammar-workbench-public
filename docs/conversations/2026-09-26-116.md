# 대화116 — C~G 검토 의견 정리

사용자는 목록 114에 대한 C~G 46개 항목의 의견을 텍스트 파일로 제출했습니다. 파일에 적힌 기준 SHA256는 현재 114 JSON과 일치했습니다. 원문의 전체 의견·46개 추가 질문과 수정 요청은 `docs/ocr-rule-inventory-116.json`의 `submitted_feedback`에 보존합니다. 현재 규칙·이전 답변의 인용은 해당 114 기준 파일에 남습니다.

이후 사용자 발화 원문:

> 이거 보고 이야기좀 해보좌

참조 파일은 로컬 `private/stage-classification-grid101-v2/report.html`입니다. 이어서 사용자가 우선순위를 정정했습니다.

> 일단 의견넣은거 먼저 정리하자

따라서 먼저 의견만 정리했습니다. 시작하려던 구현 작업은 중단했으며 채점·정렬·OCR 실행 코드 변경이나 실제 재채점은 하지 않았습니다. 보고서에 대한 대화도 후속으로 남겼습니다. 작업 전 Git 상태가 깨끗했고 중단된 작업의 코드 파일이 추가되지 않았음을 확인했습니다.

## 정리 결과

- C~G 46개: 현행 유지·해결 23개, 구현·확인 23개.
- 기존 B06·B08 포함: **25개 작업 — 로직 16 / 앱 7 / 선택 2**. F07·F10처럼 앱 요구도 있는 항목은 주 태그로 한 번만 집계합니다.
- 남은 항목은 미결정 규칙이나 사용자에게 다시 의견을 요청하는 목록이 아닙니다. 최신 사용자 정책이 확정된 구현·확인 목록입니다.
- [결정0015](../decisions/0015-cg-submission-plan.md)에 로직 순서, 075 기반 134문항 완료 조건, 앱 요구, 선택·10월 후속, 추가 질문 상태와 검증 전 가정을 정리했습니다.
- [작업 HTML 116](../ocr-rule-review-116.html)은 로직·앱·선택 필터와 기존 질문·수정 의견 작성/복사를 유지합니다. 114·115의 원본과 과거 의견은 보존합니다.

특히 학생 답 형식 F05, 전파 조건 F08(a)/(b), 공통 교사 확인 파일, 텍스트층 있는 원본 PDF 제한, 교사 수정 후 재OCR 금지, 선택 표시 자동 의미 판별 제외를 누락하지 않았습니다. D11은 실제 사례 확인 후 조건부 변경, F12의 새 사유 번호는 미정입니다. 사유 3·4 예약과 별도 답지 사유 12도 구분했습니다.

‘오답→정답 0건’은 후속 재채점의 완료 목표이며 이번 정리에서 측정한 결과가 아닙니다. ‘기존 테스트 16개’는 115의 B08 검사 1개를 추가한 현재 17개 메서드 전체와 새 검사를 확인하는 요구로 정리했습니다. 채점 로직 테스트를 이번에 실행한 것으로 기록하지 않습니다. 캘린더 일정도 변경하지 않았습니다.

문서·HTML 검증: 46개 제출 의견이 빠짐없이 저장됐고, 해결 23개와 잔류 작업 25개의 분할을 확인했습니다. 실제 브라우저에서 로직 16·앱 7·선택 2 필터, 입력·JSON/텍스트 복사·다운로드·임시 저장 복원·모바일 가로 넘침 없음을 확인했습니다. QA 파일은 로컬 `private/review116-qa/`에 있습니다. 재생성은 `python tools/build_ocr_rule_review.py --snapshot docs/ocr-rule-inventory-116.json --previous docs/ocr-rule-inventory-115.json`입니다.
