## user — 원문

## assistant — 진행 설명 요약

별도 필기 숫자와 선지 직접 표시를 나누어 인식 절차를 정리하고 기존 시험 증거와 미구현 내용을 구분한다고 안내했습니다.

## 실제 작업

객관식 채점 규격과 기존 원본 비교 시험 기록을 확인하고 [학생 답 인식 규격 초안](../multiple-choice-recognition-spec.md)을 작성했습니다. 원본 선지 등록→정렬→추가 표시 후보→숫자/선지 표시 판독→통합·보류→검토 기록 흐름을 제안했습니다. 원형 필수 조건을 제거하는 설계이며 기존 실험 코드가 이미 수정됐다는 의미는 아닙니다. 답지 정답과 인식 분리, 학생 자료 로컬 처리, 취소·메모·복수 선택 구분을 명시했습니다. 구현·학습·새 성능 시험은 하지 않았습니다. 작성 이후 최종 발화는 포함하지 않습니다.
