# 실사용 문제 1 — 문제 인쇄체만 읽고 학생 답을 놓칠 위험

2026-09-24. 사용자가 실제 파일을 첨부하려다 발견한 설계상 위험입니다. 실제 OCR 실패가 관측된 시험 결과는 아닙니다. 실제 표본은 아직 제공되지 않았습니다.

## 사용자 지적과 의미

페이지 전체 OCR에서 문제 본문이 많이 추출되더라도 학생 필기를 놓쳤다면 채점용 인식은 실패입니다. 문제 인쇄체의 인식 성공을 학생 답안 인식 성공으로 계산하지 않습니다. 앞선 합성 인쇄체 시험 8문장 중 6문장 일치는 이 위험에 대한 검증이 아닙니다.

## 다음 실제 표본 시험안

1. 원본을 눈으로 확인해 실제 학생 답안의 위치와 문자 내용을 기준으로 표시합니다. 판독 불가능한 글씨는 별도 보류합니다.
2. 페이지 전체 OCR을 실행하고 학생 답안 위치에서 무엇을 읽었는지 대조합니다. 문제 인쇄체 인식 결과는 별도로 둡니다.
3. 놓친 답은 같은 이미지에서 해당 답안 영역을 사람이 잘라 같은 OCR로 다시 읽어 봅니다. 사람이 지정한 영역이라는 사실을 기록하며 자동 답안 위치 검출 성공으로 계산하지 않습니다.
4. 전체에서는 누락되고 영역 시험에서는 읽히면 위치·영역 분리 문제를 우선 조사합니다. 영역 시험에서도 틀리면 글자 인식·화질 등의 문제를 조사합니다. 어느 한 원인으로 확정하지 않습니다.

## 기록할 항목

- 원본에 실제로 있는 학생 답안 수와 그 위치를 찾은 수.
- 각 답안의 정확한 전사, OCR 출력, 누락·불일치·판독 보류.
- 인쇄 글자를 학생 답으로 잘못 선택한 경우.
- 읽은 답을 올바른 문항에 연결했는지.
- 전체 페이지와 수동 영역 지정 시험 결과 구분.

답안 위치 찾기 → 학생이 남긴 최종 답 읽기 → 문항 연결 → 답지와 비교를 분리합니다. 학생 필기 중에서도 취소한 글씨·메모·밑줄과 최종 답은 다를 수 있습니다. 실제 작성 형태를 확인하기 전 분리 방법을 확정하지 않습니다.

OCR 출력이 없다는 이유만으로 무응답·오답으로 처리하지 않는 방안을 유지합니다. 인쇄체를 읽은 양이나 페이지 전체 인식률로 학생답 누락을 숨기지 않습니다.

## 현재 상태

사용자 지적을 기록하고 실제 표본 검증 계획을 보완했습니다. 새 OCR 실행·실제 학생 자료 검사·자동 영역 검출 구현은 하지 않았습니다. 문제지 원본이나 추가 자료를 필수 입력으로 확정하지 않았습니다.

## 추상적인 평가 설명에 대한 사용자 정정과 구체적 산출물

사용자는 “따로 평가하는거는 너무 추상적이기만함”이라고 지적했습니다. 다음 실제 시험은 첫 페이지에서 아래 결과물을 보여주는 방식으로 구체화합니다.

1. 원본 첫 페이지에서 사람이 확인한 학생의 답 위치에 번호를 붙인 표시 이미지. 이것은 자동 검출 결과가 아니라 비교 기준임을 명시합니다.
2. 각 번호에 대해 학생이 실제 쓴 글자, 전체 페이지 OCR이 해당 위치에서 읽은 글자, 놓친 경우의 답안 부분 재인식 결과를 나란히 표시한 표.
3. 인쇄 문제를 학생 답으로 읽은 사례와 아무것도 읽지 못한 사례를 원본 위치에 연결합니다. 답안이 아닌 낙서·취소 흔적을 임의로 최종 답으로 세지 않습니다.

실제 파일이 아직 없으므로 표시 이미지·결과표의 수치·실패 사례는 만들지 않습니다. 이 시험에서 사람이 자른 영역을 사용하는 목적은 원인 확인이며, 완성 앱에서 사용자가 일일이 자르는 절차를 요구하는 설계로 확정하지 않습니다. 표시 이미지는 개인정보·원자료를 포함할 수 있으므로 로컬 private 경로에 보관하고 GitHub에 원본과 함께 올리지 않습니다.
