# 공개·제출 전 점검

초기 원격 설정은 비공개를 권장합니다. 공개 전환은 사용자 별도 확인 후 수행합니다.

- 학생 이름, 연락처, 성적과 식별 가능한 답안, 비밀값이 소스와 대화 기록에 없는지 확인합니다.
- 교재·답지·기존 스킬의 이용 및 재배포 범위를 확인하고, 공개 예시는 직접 만든 자료 또는 공개 사용이 확인된 자료로 구성합니다.
- `.gitignore`가 있어도 이미 저장된 내용과 이력을 직접 확인합니다. 일반 파일 삭제만으로 과거 이력의 자료가 사라진다고 가정하지 않습니다.
- 비공개 원문과 제출용 공개 사본을 구분하며, 가림/발췌한 부분을 표시합니다.
- 출력 화면, 시험 표, 코드 버전과 설명이 실제 제출물과 일치하는지 확인합니다.
- 실행하지 않은 시험, 측정하지 않은 시간, 지원하지 않는 형식을 성공으로 기록하지 않습니다.
- 외부 링크 없이도 요약 자료를 이해할 수 있는지 확인합니다.
- 비공개 저장소의 심사자 접근을 자동으로 가정하지 않습니다.
- 제출 파일 형식·수·크기·외부 링크 허용을 실제 신청 안내에서 재확인합니다.
