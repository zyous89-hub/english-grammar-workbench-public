# 만들 프로그램: 학생 숙제 채점과 오답 어법 기록

상태: 2026-09-23 사용자 확정 목표. 구현·성능 검증은 아직 없습니다. 근거: [대화 006](conversations/2026-09-23-006.md).

## 마감

사용자 지정 종료일은 **2026-09-28 오전 (Asia/Seoul)**입니다. 정확한 시각은 미지정입니다. 3일 개발 가능성에 대한 조건부 검토는 [마감·범위 검토](deadline-and-delivery-plan.md)에 기록했으며 M1/M2 목표 축소를 확정한 것은 아닙니다.

## 사용 목적과 작업 단위

교사가 하던 학생 숙제 채점을 대신하는 프로그램입니다.

**한 세트 = 학생 한 명의 1회분 숙제.**

2026-09-24 사용자가 실무 기준으로 **객관식50문항 약3분, 주관식50문항 약10분**을 제공했습니다. 이는 근사 경험치이며 앱과 동일 자료로 측정한 비교 실험이 아닙니다. 스캔·기록 시간 포함 여부는 미확인이고 한 세트가 항상50문항인 것은 아닙니다. 시간 절감률은 실제 앱+교사 검토 시간을 측정한 뒤 비교합니다. [범위 축소 판단](grading-scope-comparison.md)

## 입력 — 사용자 확정

| 입력 | 내용 |
|---|---|
| 폴더1 | 학생의 숙제를 스캔한 JPG 파일들; 필요하면 PDF 전환도 가능하다고 사용자 설명 |
| 폴더2 | 그 학생에게 내준 숙제의 PDF 답지 파일들 |

폴더1·폴더2는 역할 이름입니다. 확장자는 JPG/PDF로 확인했으며 실제 경로·파일 수·스캔 품질은 아직 제공되지 않았습니다. 기존에 확인한 조건은 답지에 정답·어법 해설은 있지만 어법 분류는 없다는 것입니다. 스캔을 미리 텍스트로 바꾸거나 전체 문항에 분류를 붙여 오는 것을 필수 입력으로 바꾸지 않습니다.

후속 조사: [입력·OCR·기록 저장 검토](input-ocr-storage-review.md). 원본 형식 유지와 로컬 기록을 추천했습니다. 사용자는 OCR의 AI 모델 여부를 몰랐다고 설명하며 스탠드얼론·외부 데이터 송출 없는 기능이 가능한지 질문했습니다. [D-007](decisions/0007-local-ocr-boundary.md)에서 로컬 OCR 경로를 설명했으며 특정 엔진·Google Docs 사용은 미선정입니다. 실제 파일 시험은 하지 않았습니다.

## 목표 — 현재 범위는 M1과 M2

| 목표 | 해야 할 일 | 남길 결과 |
|---|---|---|
| M1: 채점·기록 | 외부 프로그램 없이 폴더1의 파일을 폴더2의 답지를 기준으로 채점 | 해당 한 세트의 채점 기록 |
| M2: 오답 어법 구분·추가 기록 | 외부 프로그램 없이 학생이 틀린 어법을 구분 | M1의 채점 기록에 연결되는 오답 어법 기록 |

흐름: **폴더1 + 폴더2 → M1 채점·기록 → M2 틀린 어법 구분·추가 기록**.

M1과 M2는 기능 목표 이름이며 앱 버전 a.b.c와는 별개입니다. M2는 학생의 성격이나 개념 이해 부족 원인을 자동 확정하는 목표가 아닙니다. 추가 문제 생성·학습 관리·어법 분석지 제작을 이번 확정 목표에 자동 추가하지 않습니다.

## 아직 결정하지 않은 세부사항

후속 출력 방향: 사용자는 추후 편집을 위해 로컬 HTML을 선호했습니다. 앱에서 수정 → 원본 채점 데이터 저장 → HTML 재생성 흐름을 제안했으며, 상세는 [D-008](decisions/0008-editable-local-html.md)을 따릅니다.

- JPG 숙제·PDF 답지의 상세 변형과 답안 형태(선택·서술·손글씨 등), 문제/답지의 연결 방법.
- 불명확한 스캔·답지 누락·복수 허용 답의 처리와 교사 확인 방식.
- 기록 항목·내부 저장 형식·화면 구성·HTML 편집/저장 방식의 세부사항.
- M2에서 틀린 문항의 출제 어법과 학생 답에 실제로 나타난 오류 어법을 구분하는 세부 정책.
- ‘외부 프로그램 없이’의 설치·실행 범위와 앱에 포함할 인식 구성요소의 허용 범위.
- 기존 ‘실행 중 AI 없음’ 요구는 철회되지 않았습니다. 스캔/손글씨 인식 방식과 이 조건의 양립 가능성을 따로 확인해야 하며, 로컬 AI/OCR 모델을 임의 도입하거나 전면 자동 채점이 검증됐다고 주장하지 않습니다.

현재는 목표를 정리하는 단계입니다. 자료를 나중에 제공하겠다는 기존 요청을 유지하며 지금 새 자료 요청이나 앱 구현을 시작하지 않습니다.

## 검토용 기록 구조 제안 — 아직 확정 아님

M1 기록 후보: 세트 식별자, 원본 스캔·인쇄 쪽·문항, 읽은 학생 답, 대응 답지 위치·정답, 판정, 근거, 확인 필요 여부.

M2 추가 기록 후보: 연결된 M1 문항 식별자, 어법 ID·명칭, 분류 근거, 분류 상태, 교사 수정 이력.

읽지 못한 답안을 자동 오답 처리하지 않고 판독 보류를 별도로 두는 방식을 제안합니다. 한 문항의 기록을 기준으로 요약과 통계를 계산하여 누락·중복을 확인합니다. 세부 항목은 실제 표본과 사용자 검토 후 확정합니다.
