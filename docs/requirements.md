## 미정

객관식 입력 형식과 지원 범위의 경계, 범용 문항·선지 연결 구조, 교사 확인 화면과 저장 세부 동작, 배포 기술, 지원 PC 사양과 독립 검증 기준은 남아 있습니다. 어법 분류 체계·분류 성능은 이번 M1 완료 조건이 아닙니다. 저작권 자료는 로컬에서만 시험하고 저장소·배포본에는 포함하지 않습니다.

## M1 완료 기준 — 세부 검증 정책은 제안

M1은 한 세트의 학생 스캔·원본·답지를 연결하고, 객관식 학생 답 판독·답지 비교·교사 확인과 수정·로컬 저장·재열기·보고서 출력을 하나의 독립 실행 앱에서 처리해야 합니다. 판독 불가·답지 연결 실패·보류를 실제 오답과 구분하며, 학생 데이터를 외부로 보내지 않는 실행과 개발 환경 없는 PC에서의 동작을 검증해야 합니다. M2를 제외해도 이 M1 요구를 자동으로 축소하지 않습니다.

네 단계 중단·사유 기록은 합의됐으나 구현·검증 전입니다. 1~3단계 실패는 해당 범위의 후속 처리를 중단하고, 4단계 후보 충돌은 문항의 자동 확정을 보류합니다. 복수 답 자체는 실패 사유가 아닙니다. 12번 답지 추출은 확인한 객관식 자료에서 해결 처리하되 새로운 형식·스캔형까지 검증 완료로 표현하지 않습니다. 서술형 채점·정답과 해설 분리, 구김 보정은 보류합니다.

이는 목표이지 현재 구현된 기능이 아닙니다.
