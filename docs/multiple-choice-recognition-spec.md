# 객관식 학생 답 인식 절차 초안

2026-09-24. 사용자가 학생 답 인식 방식을 정리하도록 요청했습니다. 아래는 설계 제안이며 모든 표기 지원·자동 인식 성능이 구현 또는 검증됐다는 뜻이 아닙니다. 채점 기준은 [객관식 채점 규격](multiple-choice-grading-spec.md)을 따릅니다.

## 목표와 처리 경계

후속 사용자 제안으로 **객관식 확정 후 학생 표기 방식별 판독**을 준비하는 방향을 채택합니다. [결정0010](decisions/0010-choice-response-methods.md)의 번호 별도 작성·선지 직접 표시·제외하며 별도 답 작성 세 경로를 참조합니다. 문항 단위 혼합 처리·충돌 보류는 assistant 세부 제안이며 아직 구현되지 않았습니다. 정오답 비교 규칙은 공통으로 유지합니다.

문항마다 학생의 최종 선택 번호 집합과 판독 근거를 얻습니다. 출력은 선택 확인 / 무응답 확인 / 판독 보류로 나눕니다. 정답 집합은 인식 모듈에 주지 않고 학생 선택을 확정한 뒤 채점 모듈에서 비교합니다. 정답 여부·문법 지식으로 흐릿한 표시를 보정하지 않습니다. 단일 선택 지시가 있다고 감지한 여러 답 중 하나를 자동 삭제하지 않습니다.

학생 이미지·필기 후보·판독·검토 기록은 로컬에서 처리합니다. 원본 구조 분석을 외부 API에 맡길지는 앞선 조건에 따라 별도 결정하며 학생 자료를 전송하는 대체 동작은 두지 않습니다.

## 1. 원본에서 문항 지도 준비

교재·판본·페이지 대응을 확인하고 문항 번호, 본문/선지 영역, 선지별 번호·내용·위치, 단일/복수 선택 조건, 답란이 있으면 그 위치를 등록합니다. 선지 묶음과 예시·문항 번호를 구분합니다. 최초 등록 오류가 모든 학생에게 반복되지 않도록 교사가 원본 위 위치와 번호 대응을 검토하는 흐름을 제안합니다. 교재·원본 변경 시 등록 정보를 재검토합니다.

## 2. 학생 페이지 정렬 및 입력 품질 확인

회전·크기·기울기를 원본과 맞춘 후 문항별 정렬과 스캔 잘림을 확인합니다. 전체 페이지가 맞아 보여도 한 문항이 휘거나 잘릴 수 있으므로 해당 문항은 보류할 수 있습니다. 원본·정렬본·변환 정보를 보존합니다. 정렬 실패를 무응답으로 처리하지 않습니다.

## 3. 학생이 추가한 표시 후보 수집

원본과의 차이는 학생 표시 위치를 찾는 단서로 사용합니다. 인쇄 농도·그림자·스캔 잡음도 차이에 포함될 수 있고 인쇄와 겹친 필기는 사라질 수 있으므로 차이 영상만으로 답을 확정하지 않습니다. 판독 입력은 학생 원래 이미지와 원본의 대응 영역입니다.

문항의 선지 영역·명시 답란·주변 여백에서 후보를 찾고 그 밖의 미배정 표시도 누락 여부를 확인할 수 있도록 남깁니다. 가장 가까운 문항이라는 이유만으로 강제 연결하지 않습니다. 작은 조각들을 합칠 때 숫자 획이 나뉜 경우와 별개 필기를 구분하고 자르기 전 문항 전체 맥락을 함께 보존합니다. 원의 존재·원형 비율을 후보 수집 필수 조건으로 사용하지 않습니다.

## 4. 표기 방식에 따라 판독

| 표기 후보 | 판독 방법 제안 | 주의할 점 |
|---|---|---|
| 여백·답란에 쓴 번호 | 온전한 필기 영역의 숫자·구분기호를 인식하고 해당 문항에 연결 | 주변 문항 번호·계산 메모를 학생 답으로 읽지 않음. 다중 번호 입력 지원 필요 |
| 원으로 둘러싼 필기 번호 | 원과 숫자를 포함한 영역에서 번호 인식 | 원을 무조건 지우거나 안쪽만 자르지 않음 |
| 선지 번호·내용에 직접 표시 | 원본 선지 위치와 추가 표시의 관계로 선택 후보 판별 | 원본 인쇄 숫자를 새 필기로 오인하지 않음. 체크·밑줄·X의 의미는 모양만으로 확정하지 않음 |
| 여러 선지 또는 여러 필기 번호 | 각 후보를 수집하고 실제 선택 집합으로 정리 | 하나만 고르는 문제라도 하나로 강제 축소하지 않음 |
| 지움·취소·다시 쓴 답 | 원래 표시·수정 표시의 관계를 문항 전체에서 검토 | 더 진함·더 큼·오른쪽 위치만으로 최종 답 결정 금지 |
| 선지 내용을 그대로 쓴 답 또는 기타 표기 | 별도 표기 형태로 보존하고 초기에는 교사 확인 | 숫자 인식기에 강제 입력하거나 비슷한 선지로 대체하지 않음 |

선지 직접 표시 판독은 글자를 읽는 OCR만으로 완료되지 않으며 표시의 위치·선택/메모/취소 의미를 구분하는 규칙 또는 모델과 검토 경로가 필요합니다. 구체 모델·기준은 아직 미정입니다. 지원 가능성 설명과 실제 표본에서의 성공을 구분합니다.

## 5. 후보 통합과 보류

필기 번호와 선지 표시가 같은 선택을 명확하게 가리키면 하나로 통합하되 원래 근거를 모두 남깁니다. 서로 다른 번호를 가리키면 곧바로 복수 응답으로 확정하지 않고 실제 복수 선택인지 수정·메모인지 확인합니다. 명백히 여러 개를 최종 선택한 경우에만 그 집합을 넘겨 단일 선택의 복수 응답 오답 규칙을 적용합니다.

선지 범위 밖 숫자·모호한 문자·문항 배정 충돌·영역 잘림·인식 방법 간 불일치는 판독 보류입니다. 동일 엔진의 반복 일치를 독립적인 정답 증거로 삼지 않습니다. 높은 OCR 신뢰도 하나로 자동 정답을 확정하지 않습니다. 무응답 확인에는 해당 문항의 스캔과 영역이 온전하고 표시가 누락되지 않았다는 검사가 선행해야 하며 구체 자동 확정 기준은 검증 전입니다.

## 6. 검토 화면과 기록

교사는 원본 문항, 학생 문항 전체, 확대된 표시 후보, 연결된 선지, 인식된 번호, 보류 이유를 함께 볼 수 있어야 합니다. 답안 조각만 보면 놓치는 메모·취소·옆 문항 관계를 확인할 수 있어야 합니다. 학생 선택을 수정하면 이전 판독·근거·교사 수정값과 시각을 보존합니다. 학습 라벨 검토에서는 답지를 숨겨 정답에 맞춘 추정을 줄이는 안을 제안합니다.

## 기존 증거와 첫 구현 순서

- [기존 원본 비교 시험](verification/2026-09-24-mixed-reference-ocr.md): 문항 탐색 구역은 수동 지정했고 객관식 후보 검출에 원형 성분을 사용했습니다. 2번의 분리 실패가 있으므로 위 규격 구현 완료로 보지 않습니다.
- 첫 구현은 기존 원형 필수 조건을 제거한 후보 추출과 2번 영역 보완, 9문항의 원본/학생/후보/출력 비교입니다. 원본 선지 자동 등록도 아직 검증되지 않았으므로 교사 확인 좌표로 시작하는 경우 그 사실을 표시합니다.
- 이후 번호만 쓰기·선지 직접 표시·복수 선택·수정·무응답 표본으로 테스트를 확장합니다. 현재 한 학생의 원 표기 표본을 전체 학생의 기준으로 쓰지 않습니다.
- 숫자 인식 학습과 선지 표시 판별 학습은 입력·라벨이 다릅니다. 영역 추출 실패를 숫자 학습으로 덮지 않고, 기존 인식 기준 결과를 만든 뒤 필요한 부분을 학습합니다. 교사가 확인한 실제 선택을 라벨로 사용하고 별도 학생·교재로 평가합니다.

최초 문서 작성에서는 새 인식 시험·학습·API 호출을 수행하지 않았습니다. 후속 선지 직접 표시 시험 (비공개 기록)에서 원본40개 선지 등록과 원형 필수 조건 없는 번호 주변 변화 후보 검출·OCR40개 실행을 수행했습니다. 후보 과검출과 선택/제외 의미 판별 미구현이 확인됐으며 위 전체 절차의 구현 완료가 아닙니다.
