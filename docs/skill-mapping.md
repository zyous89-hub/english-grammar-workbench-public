후속 변경: [D-006](decisions/0006-grading-first-milestones.md)에서 스캔 숙제 채점(M1)과 오답 어법 기록(M2)을 확정했습니다. 아래는 그 이전의 조사·범위 제안입니다. 특히 스캔·채점을 범위 밖으로 둔 판단은 대체되었으며, 기존 HTML 출력 중심 계획으로 최신 목표를 제한하지 않습니다.

## 다음 첫 구현 단위 — 제안, 착수 보류

**원문 보존·문항 식별·입력 검증·저장/복원**을 가장 작은 단위로 제안합니다.

- 문제·정답·해설을 문자열 그대로 보존하고 분류는 필수 입력으로 요구하지 않습니다.
- 자료 식별자와 문항 식별자를 분리하고 중복·누락을 표시합니다. 자동 연결을 추측하지 않습니다.
- 원문 왕복 보존, 다른 자료의 같은 번호, 같은 자료의 중복, 빈 해설, HTML 특수문자, 잘못된 파일 형식을 검사합니다.
- 원본 입력 형식이 아직 없어 내부 JSON 초안과 실제 가져오기 형식을 구분합니다. 문항·선지 구조는 표본 확인 후 결정합니다.
- 분류명·언어 해석에 의존하지 않는 코어부터 시작할 수 있으나 사용자가 이번에는 내용 파악만 요청하여 착수하지 않습니다.
- 스택은 미정입니다. 순수 JavaScript는 브라우저/데스크톱 양쪽에서 공유할 수 있는 후보이며 Electron 채택·Windows 전용 배포를 확정한 것은 아닙니다.

이 단위 이후 실제 표본 확인 → 사전/분류 단위 검토 → 키워드 비교 기준과 제외 규칙 → 교사 확인 → 기준 HTML 출력 순으로 검토합니다. 기존 분석지 전체 기능을 이 작은 단위로 대체하지 않습니다.
