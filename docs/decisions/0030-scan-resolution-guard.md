# 결정0030 — 학생 스캔 해상도 자동확정 안전장치

- 날짜: 2026-09-27
- 상태: 사용자 요청 구현 및 검증 완료.
- 근거: [대화163](../conversations/2026-09-27-163.md). 비교 기준은 결정0029/대화162.

학생 원본 이미지의 짧은 변이 **2400~2560px(양 끝 포함)** 밖이면 페이지 내 모든 문항의 자동확정을 막습니다. 기존 판독·후보·소속·다른 보류 사유는 유지합니다. 해당 페이지의 모든 문항에 1단계·사유17·`scan_resolution`과 `스캔 해상도 확인 필요: 300dpi로 스캔해 주세요 (현재 짧은 변 N px)`를 기록합니다. 숫자 후보가 없거나 이미 보류여도 같은 사유를 추가합니다.

실제로 추출에 쓴 학생 스캔 사본의 픽셀 크기를 읽으며, 정렬용 축소본·조각·DPI 메타데이터로 대체하지 않습니다. 입력을 허용 범위에 맞추기 위한 확대·축소는 하지 않습니다. 기존 정렬·판독 전처리는 바꾸지 않습니다. 파일을 읽을 수 없으면 자동확정하지 않고 오류로 중단합니다.

정상 134문항 양안의 자동확정 22/20, 보류 112/114와 모든 후보·답·판정·보류 사유가 162와 같습니다. 1654px 시험 사본의 2쪽 11문항은 모두 지정 사유로 보류, 다른 123문항 불변입니다. 새 OCR·재배정 없이 162 결과를 재사용했고 전체 70개 검사(추가 단위테스트 1개), 결과 계약 및 실제 화면 확인을 통과했습니다.

검증 자료는 반복 사용한 개발 표본입니다. 학생 원자료·확인 전사·교사 수정은 보존하며 로컬 시험 사본과 이미지 보고서는 Git/Drive에 올리지 않습니다.
