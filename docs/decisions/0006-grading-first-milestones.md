# D-006: 채점 중심의 M1·M2 목표 확정

날짜: 2026-09-23. 상태: 사용자 명시 목표. [대화 006](../conversations/2026-09-23-006.md), [현재 제품 목표](../product-goals.md).

기존 문서는 해설 분류와 HTML 자료 제작을 중심으로 설명했습니다. 사용자가 이번에 만들 프로그램의 목적을 숙제 채점으로 구체화했습니다.

- 입력: 학생 한 명의 1회분 숙제 스캔 폴더 + 해당 숙제 답지 폴더.
- M1: 외부 프로그램 없이 답지 기준 채점·기록.
- M2: 외부 프로그램 없이 틀린 어법 구분·추가 기록.
- 수동 채점 시간: 사용자 추후 제공, 현재 미제공.

이번 목표를 우선합니다. 이전의 텍스트/표 입력 제한 제안으로 스캔 입력을 대체하지 않습니다. 기존 스킬 이식표의 ‘스캔 인식·채점은 이번 범위 밖’이라는 이전 범위 판단은 이번 결정으로 대체합니다. 인식 방법·지원 범위는 여전히 미정입니다.

HTML 출력은 가능한 기록 방식 중 하나로 검토하되 M1/M2에 필수라고 임의 확정하지 않습니다. 기존 AI 없는 실행 조건은 유지하며 외부 프로그램 불필요 조건과 구분합니다. 기술적 구현 가능성·정확도·속도를 이번 목표 확정만으로 입증하지 않습니다.

이번 실제 변경은 목표·요구사항·작업 목록·검증 계획과 대화 기록의 갱신입니다. 앱 코드·태그·릴리스·성능 결과는 추가하지 않았습니다. 아직 빌드 버전이 없으므로 설명용 숫자를 실제 버전으로 승격하지 않습니다.
