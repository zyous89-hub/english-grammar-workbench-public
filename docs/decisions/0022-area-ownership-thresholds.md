# 0022 — 문항 소속 면적 기준 50%·60%·70% 비교

2026-09-27 사용자 요청. 대화149 (비공개 기록).

기존 147의 페이지 전체 OCR 결과를 재사용해 문항 소속만 비교합니다. 사용자는 세 비율을 각각 시험하고 실제로 올바른 범위에 붙었는지 확인하도록 요청했습니다. 특정 비율을 운영 기본값으로 선택하지 않았습니다.

## 계산·연결 정책

- 분모는 기존 `ink_box` 사각형의 전체 면적입니다. 이는 검출 잉크의 외접 사각형으로, 검은 획 픽셀 수나 사방 4픽셀 여백을 더한 최종 이미지 면적과 다릅니다.
- 분자는 그 사각형과 문항 `zone`의 교차 면적입니다. 문항 범위 수치·OCR 결과·인쇄물 삭제·채점 점수 경계는 바꾸지 않습니다.
- `minimum_overlap` 이상인 문항이 정확히 하나면 그 문항에만 연결합니다. 이전 교차 목록은 `intersections`에 보존합니다.
- 정확히 50:50인 경우, 여러 범위가 기준을 동시에 충족하는 경우, 어느 범위도 기준에 못 미치는 경우에는 원래 후보와 확인 상태를 유지합니다. 순서·OCR 점수·답지로 승자를 정하지 않습니다.
- 어느 문항에도 닿지 않으면 미배정으로 보존합니다. 이 기준만으로 바깥 여백 답을 가까운 문항에 자동 연결하지 않습니다.
- 기존 호출에서 옵션을 생략하면 종전 145/147 동작을 유지합니다. 운영 기본값 승격은 하지 않습니다.

개발용 실행:

```text
python -m tools.page_first_ocr assign <source> <147 OCR> <새 출력> --annotations <기존 의미 주석 결과> --minimum-overlap 0.5
```

0.6·0.7을 별도 새 출력 폴더로 실행합니다. 새 OCR이나 채점이 아니라 소속 비교입니다. `evaluation.json`은 기존 어댑터의 전부 보류 초기값이며 최종 채점 결과가 아닙니다.

## 확인 범위와 한계

147의 1,053조각 전부에 적용하고, 기존 단일 소속 939조각이 그대로임을 검증했습니다. 기존 소속 확인/미배정 114조각은 18쪽 사진 및 확대 사진으로 따로 검토했습니다. 사진 검토는 알고리즘 입력에 넣지 않은 개발용 Codex 검토이며, 사용자가 소속을 명시 확인한 q22 사례 외에는 교사 확정 소속표가 아닙니다. 소속 불명확 표시는 정답표로 강제하지 않습니다.

사진상 다음 문항 답을 제목 위에 쓴 사례나 제목에 표시한 획은 면적이 위 문항에 더 많을 수 있습니다. 실제 q103 답이 q102에 74.65% 걸려 세 기준 모두 위 문항으로 연결되는 반례가 있습니다. 비율을 높여도 이 문제를 모두 없애지는 못합니다. 최종 채점 영향 검증은 이번 작업에서 실행하지 않았습니다.
