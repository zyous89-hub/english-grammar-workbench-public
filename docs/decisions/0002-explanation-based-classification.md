# D-002: 해설이 있지만 분류는 없는 입력

상태: 입력 조건은 사용자 명시; 아래 처리 방식은 assistant 제안. 기록일: 2026-09-23.

## 조건

문제·정답·어법 해설을 제공할 수 있지만 어법 분류는 없습니다. 분류가 입력에 있다고 가정하지 않습니다.

## 제안

기존 스킬의 실제 분류표를 먼저 확보합니다. 해설의 표현 조합, 제외 표현, 정답의 수정 지점을 이용해 분류 후보와 근거를 표시합니다. 부족하거나 충돌하는 사례는 교사에게 확인받습니다.

## 기각을 제안하는 방식

해설에 문법 용어가 등장한다는 이유만으로 전부 주된 출제 어법으로 확정하는 방식. 단순 키워드 방식을 비교 기준으로 구현할 수는 있습니다.

## 미정

문항 전체/선지별 처리, 다중 분류 허용, 주된 어법/관련 어법 분리, 세부 분류명. 예시 분류는 최종 체계가 아닙니다.

## 검증

교사가 검토한 분류 기준 자료와 비교합니다. 문제 정답을 분류 정답으로 대체하지 않습니다. 아직 결과가 없습니다.
