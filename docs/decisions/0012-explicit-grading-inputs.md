# D-012 — 학생 폴더·답지 파일·원본 파일 직접 지정

2026-09-26 대화082 사용자 확정: 학생 스캔 폴더, 답지 파일, 원본 파일을 사용자가 각각 선택합니다. 파일명 유사성/다운로드 폴더 검색 결과 순위로 원본을 자동 선택하지 않습니다. 이전 입력 폴더2 중심 요구의 파일 선택 방식은 이 요구를 우선합니다.

원본/답지가 한PDF면 동일 파일을 두 역할로 선택할 수 있습니다. 답지 시작 페이지 지정은 현재 파서의 구현상 입력이며 사용자 발화에 없던 보조 설정입니다. 선택만으로 각 학생 페이지/문항과 원본/답지가 자동 연결된다고 가정하지 않습니다.

범용 파일 선택 화면은 최종 앱 요구사항입니다. 현재는 개발용명령행 진입점만 구현했습니다. 교재별 페이지 매핑과 텍스트 파서의 일반화는 남아 있습니다. 외부 전송/생성형AI 없이 구현 가능한 범위입니다.

두 단 구획은 사용자가 수용했습니다. 고정 여백 제거/대체 세부 동작은 아직 확정하지 않았습니다. [근거·한계·검증](../ocr-rule-review-response-082.md).
