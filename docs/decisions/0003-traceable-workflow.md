# D-003: 개발 과정과 결과물의 연결 기록

상태: 사용자 기록 요청 확인; 세부 운영 방식은 제안. 기록일: 2026-09-23.

## 사용자 요청

지금부터의 대화를 GitHub 저장소에 남기고, 저장소와 최종 결과물로 개발 흐름을 포트폴리오에서 보여주고자 합니다.

## 제안하는 연결

대화 → 사용자 결정/AI 제안 구분 → 작업 항목 → 코드·규칙 변경 → 실행한 시험 → 결과 → 제출 자료.

원문은 보관하고, 심사용 자료는 별도의 요약과 구체적 증거 링크를 제공합니다. 긴 대화나 많은 커밋 자체가 우수한 결과라는 주장은 하지 않습니다.

## 현재 제약

이 대화의 GitHub 연결로 조회는 가능하지만 생성·커밋 도구가 제공되지 않았고, 인증된 CLI 업로드 경로도 확보되지 않았습니다. 따라서 로컬 Git 초기 저장소만 만들고 원격 생성·업로드는 미실시로 남깁니다.

## 공개

비공개 시작을 제안합니다. 공개 전환, 대화 공개, 학생 자료 공개는 자동 실행하지 않습니다. 민감정보는 비공개 저장소에도 기본적으로 커밋하지 않습니다.
