# D-007: 스탠드얼론·외부 데이터 송출 없음과 로컬 OCR

날짜: 2026-09-23. 상태: 사용자 질문에 대한 기술 검토와 요구 해석; 엔진 채택·구현은 미실시. [대화 007](../conversations/2026-09-23-007.md).

## 사용자 발화

사용자는 OCR을 프로그램으로 생각했고 AI 모델을 쓰는지 몰랐다고 설명했습니다. 이어 ‘스탠드얼론 + 외부로 데이터 송출없이 기능하는지?’라고 질문했습니다.

## 답변과 근거

OCR은 프로그램으로 제공되며 내부에서 학습된 인식 모델을 사용할 수 있습니다. 해당 엔진과 모델을 앱에 포함해 PC 안에서 처리하는 경로가 있으므로 외부 AI 서비스 호출은 필수가 아닙니다. 공식 로컬 추론 근거와 후보의 한계는 [조사 문서](../input-ocr-storage-review.md)에 연결했습니다.

설치본에 필수 파일을 포함하고 사용 중 다운로드·원격 API·클라우드 대체 처리·자료가 담긴 원격 로그 전송을 제거하는 구성을 제안합니다. 통신 차단 실행과 통신 시도 관찰은 별도 검증입니다. 현재 앱이 이 조건을 통과한 것은 아닙니다.

## 이전 조건과 관계

기존 D-001의 ‘AI 없음’을 이번 질문에 비추어 재검토합니다. 확인할 핵심 실행 조건은 스탠드얼론과 외부 데이터 송출 없음입니다. 로컬 OCR 인식 모델을 사용할 수 있다는 설명을 했지만 특정 모델·기술 스택·학습 방식의 선택까지 승인받았다고 기록하지 않습니다. 채점·M2 분류를 생성형 AI에 맡기는 방식을 제안한 것도 아닙니다.

## 저장 방식 추천

외부 송출 금지가 기록에도 적용되면 Google Docs를 기본 저장소로 사용할 수 없습니다. 앱 내부 로컬 기록·조회와 로컬 보고서 내보내기를 추천합니다. 클라우드 공유는 별도 예외가 허용될 때 검토하며 자동 업로드하지 않습니다. 저장 암호화·백업·복구와 실제 데이터 저장 위치도 함께 설계해야 합니다.
