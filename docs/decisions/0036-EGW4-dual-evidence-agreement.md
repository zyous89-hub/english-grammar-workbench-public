# 결정0036 — EGW4 두 독립 증거 일치

- 기록일: 2026-09-28.
- 상태: 개발용 134문항 검증 완료. 기본 제안안 자동확정37, 참고 사용자안39, 판독 오류0.
- 기준: ee9b407 판독·재판독과 5453482 선택 표시 측정은 보존. 새 규칙은 `tools/dual_evidence.py`에서 기존 보류 결과에만 적용.
- 상세: [EGW4 검증 기록](../conversations/2026-09-28-EGW4-dual-evidence.md).

## 조건

1. 5453482와 같은 추천 함수로 표시 번호가 하나이고 답지 정답이 하나인 보류 문항만 검토합니다. 기존 자동확정 문항은 그대로 반환합니다.
2. 원본 문항 context의 인쇄 번호 중심 상자(32×32px)를 페이지 좌표로 환산합니다. 조각의 기존 상자가 인쇄 ①~⑤ 중 어느 상자와든 겹치면 그 조각 전체의 숫자 판독을 제외합니다. 접촉만 하고 공통 면적이 없는 경우는 겹침이 아닙니다.
3. 나머지 조각의 최초·현재·저장된 재판독과 각 크기별 판독에서 숫자를 수집합니다. 0.5 이상 중 가장 높은 판독이 선택 표시와 같아야 하며, 다른 숫자/복수 숫자 판독이 하나라도 있으면 보류합니다. 이전 재판독에서 채택되지 않은 읽기 값도 요청한 ‘첫 판독과 재판독 전체’에 포함합니다. 기존 OCR 점수·재판독 채택 결과는 수정하지 않습니다.
4. 최고 점수가 0.5 이상 0.8 미만이면 해당 조각을 이번 규칙의 후보로만 넣고 기존 `question_review`를 다시 적용합니다. 이미 채택된 0.8 이상 후보는 신뢰도 완화 없이 선택 표시와 겹친 저신뢰 조각의 F08(b)만 해소할 수 있습니다. 미채택 0.8 이상 재판독 하나만으로 확정하지 않습니다.
5. F08(b) 예외는 사유6인 조각이 선택된 같은 번호의 인쇄 상자와 겹칠 때만 추가합니다. 원래 정책의 예외 목록은 유지합니다. 다른 조각 때문에 남거나 새로 발생한 F08(b)는 제거하지 않습니다.
6. 문항 소속·선택 표시 미해석·답 존재·F05·F06·F10·F12·답지 개수·해상도·답지 해석 등 다른 보류는 완화하지 않습니다. 기존 F06(re-read)도 유지합니다. 재판정 후 보류가 남으면 문항 결과·사유를 원래 상태 그대로 보존하고 검토 시 발생한 사유만 감사 파일에 남깁니다.

0.5는 고정값입니다. 문항 번호, 전사, 답지 숫자를 일치할 답 선정에 사용하지 않습니다. 답지는 단일 정답 여부와 최종 학생 답 채점에만 사용합니다. 기존 0.8 기준과 원본/재판독 조정 규칙을 바꾸지 않았습니다.

## 좌표·출처

원래 source/questions.json의 문항 시작점과 스캔/참조 페이지 크기 비율을 사용해 `(context좌표 + round(문항시작 × 배율)) / 배율`로 환산합니다. 픽셀을 재정렬하거나 확대하지 않습니다. context 해시와 둥근 좌표로 잘린 실제 크기를 검사합니다. 하단 확장 후 167 문항 영역을 원래 147 context의 시작·크기 계산에 쓰지 않습니다.

원래 결과가 현재 분류·정렬·정책 예외로 정확히 재현되는지 검사한 후 새 결과를 만듭니다. 출력은 새 폴더만 허용하고 입력 해시를 검증합니다. 새 확정 문항에는 실제 판독 입력 이미지와 선택 표시 이미지를 `두 증거 일치 · 손글씨 N 0.xx + 선택 표시 N`으로 추가합니다. 기존 근거·교사 수정은 복사 보존합니다. 새로운 결과 ID·생성 시각과 새 확정 문항의 규칙 버전을 기록합니다.

## 실행

첫 인수는 추천 근거를 붙이기 전 양안 결과 폴더, 둘째는 동일 실행의 baseline/assigned/comparison 폴더를 포함한 trial입니다. 표시 측정 파일은 반드시 같은 제출의 원래 300dpi context로 생성해야 합니다. 전사를 받는 인수는 없습니다.

```powershell
private/paddle-env/Scripts/python.exe -m tools.dual_evidence private/e167/result/CE private/e167/CE-trial private/external-batch-20260925/4C-rerun071-source private/EGW4-markref/measurements/measurements.json private/EGW4-new-dual
```

출력 `{duplicate,broad}/result.json`이 새 채점 결과, `dual-evidence.json`이 전후 판정·제외 조각·숫자 출처·미해소 사유·입력 해시입니다. 이후 기존 `choice_mark_recommendations attach`를 양안에 적용해 **남은 보류**에만 추천을 붙입니다. `report_choice_recommendations`는 ‘두 증거로 새로 확정’ 필터와 양안 비교를 제공하며, `package_result_review`는 같은 근거를 앱 화면에 표시합니다. 독립 표본은 EGW3가 이 코드 버전으로 별도 검증합니다.
