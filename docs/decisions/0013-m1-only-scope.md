# D-013 — 이번 범위는 M1 객관식 채점·기록까지

상태: 2026-09-26 사용자 확정.

사용자 요청 원문: “내일 오후에는 일단 앱개발 시작해야할테니 그전까지 하는데까지 끝내봐야지 일단 ㅇㅋ” / “M2도 쳐내자... 마일스톤 1까지로 줄입시다. ㅠ”

## 결정

- 이번 프로젝트의 완료 범위는 M1 객관식 채점·기록까지로 줄입니다. M2 오답 어법 구분·추가 기록은 제외합니다.
- M1의 입력 선택·페이지/문항 연결·학생 답 판독·답지 비교·교사 확인과 수정·로컬 저장·재열기·보고서 출력·독립 실행 검증은 유지합니다. M2 제외를 근거로 이 요구를 자동 축소하지 않습니다.
- 서술형 채점과 정답·해설 분리, 구김·훼손 보정과 A07 주관식 밑줄은 기존 보류를 유지합니다. 기존 10월 후속 알림을 이번 결정으로 변경하지 않습니다.
- 12번 답지 추출은 현재 확인한 객관식 자료 범위에서 해결 처리합니다. 새 배치·스캔형 답지까지 검증 완료라는 뜻은 아닙니다.
- 네 단계 중단·사유 기록은 합의 상태이며 코드 구현·검증 전입니다. 다음 실행에 적용할 요구로 두고 현재 실행 중인 시험의 코드·입력·평가 기준은 변경하지 않습니다.
- 2026-09-27 오후(한국 시간) 앱 개발 시작을 목표로 사전 규칙 검토를 진행합니다. 자동 실행 예약이나 완성 보장은 아닙니다. 기존 2026-09-28 오전 마감은 변경하지 않았습니다.

## 이유와 영향

앱 개발 착수를 앞두고 이번 범위를 줄인 사용자 결정입니다. M2 설계·조사·대화 기록은 삭제하지 않고 역사 기록으로 보존합니다. 이전 결정 0006의 M1/M2 동시 목표와 대화 113의 M2 포함 계획은 이번 범위에 한해 대체합니다. M2 재착수는 별도 범위 결정이 필요합니다.

독립 실행·외부 송출 없는 학생 데이터 처리, 교사 확인·수정과 안전한 기록 보존, 저작권 자료의 로컬 전용 정책은 그대로 유지합니다. 개발용 명령행 도구가 실행됐다는 사실을 앱 구현·패키징 완료로 표현하지 않습니다.
