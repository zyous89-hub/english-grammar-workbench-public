# 결정0034 — EGW4 보류 문항의 선택 표시 추천 근거

- 기록일: 2026-09-28 (요청과 개발 시작은 2026-09-27)
- 상태: 개발용 134문항 구현·검증. 자동확정 규칙은 `ee9b407` 그대로.
- 근거: EGW4 작업 기록 (비공개 기록).

## 경계

추천은 채점이 끝난 `result.json`의 `judgement == 보류` 문항 중 답지 정답을 숫자 한 개로 해석할 수 있는 문항에만 붙입니다. 확정 답, 읽은 답, 채점, 보류 단계·사유, 기존 근거는 변경하지 않습니다. 추천 숫자는 `evidence_images`의 이름표와 번호 주변 이미지에만 추가합니다. 전사는 추천을 생성한 다음 개발 평가에만 사용합니다. 답지 숫자와 맞는 표시를 고르지 않습니다.

`tools/choice_mark_recommendations.py`가 기존 원본 PDF 보호 번호 좌표 및 저장된 페이지 정렬을 재사용합니다. 원본 참조 이미지 좌표계에서 모든 문항에 고정값을 적용합니다. 이번 참조 크기는 1334×1888px이며 원스캔/OCR 크기의 픽셀과 구분합니다.

| 항목 | 고정 조건 |
|---|---|
| 번호 | PDF의 ①~⑤. 기존 문항 구역에 전체 상자가 유일하게 속한 경우 |
| 측정 범위 | 번호 상자 둘레 4px, 그 왼쪽에 12px 추가 띠 |
| 추가 잉크 | 기존 적응 이진화 31/14, 원본 명암 195 미만 인쇄를 사방 2px 확장해 제외 |
| 표시 | 남은 잉크 40px 이상. 모양을 체크로 한정하지 않아 동그라미도 포함 |
| 취소 | 같은 번호 높이 띠에서 측정 영역에 닿는 잉크 연결 성분의 가로 폭 200px 이상. 가로 틈 4px까지만 연결 |
| 추천 | 취소를 제외한 표시가 정확히 하나 |

문항별 조정·최고 점수 선택·새 OCR은 없습니다. 200px 취소선 합성 경계 테스트는 통과했으나 실제 개발 표본에서는 취소로 검출된 번호가 0개입니다. 인쇄 제거로 길게 끊긴 선이나 기울어진 선까지 완전히 판별한다는 뜻이 아닙니다. 체크의 윗획이 위 번호에 걸려 추천이 틀리는 경우도 실제로 확인됐습니다. 이 결과를 자동확정에 사용하지 않습니다.

추천 이미지의 ID는 `choice-mark-recommendation`, 이름표는 `추천 ④ · 선택 표시 기반 · 확인 필요` 형식입니다. 앱은 기존 파일 계약대로 이름표와 이미지를 표시하며 이를 답으로 파싱하지 않습니다. 결과 형식은 v1 유지, 새로운 결과 ID·생성 시각만 부여합니다. 입력 결과를 덮어쓰지 않고 새 출력 폴더를 요구하며 같은 폴더의 교사 수정 파일은 복사 보존합니다.

`tools/report_choice_recommendations.py`는 양안 보류 목록·추천·틀린 추천과 이미지 필터를 제공합니다. 동일 사진을 한 번만 내장해 최종 HTML은 26,283,868바이트입니다. 학생 자료·전사·보고서는 로컬 전용입니다. EGW3의 채점 기준 커밋 `ee9b407`과 `egw3-grading` 브랜치는 변경하지 않습니다.
