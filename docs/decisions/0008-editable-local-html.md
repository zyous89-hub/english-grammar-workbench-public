# D-008: 추후 편집을 위한 로컬 HTML 보고서

날짜: 2026-09-23. 근거: [대화 008](../conversations/2026-09-23-008.md).

## 사용자 방향

사용자는 추후 편집을 쉽게 하기 위해 HTML이 적합하겠다고 밝혔습니다. 로컬 HTML을 기본 보고서 방향으로 둡니다. 이것이 HTML 편집기·파일 저장 방식까지 모두 확정했다는 뜻은 아닙니다.

## 구현 제안

- 사용자는 앱 화면에서 채점 판정·어법 분류·메모를 수정하고 저장합니다. HTML 코드를 직접 고치도록 요구하지 않습니다.
- 수정 가능한 원본 채점 데이터와 수정 이력을 로컬에 보관하고, 해당 데이터에서 HTML을 다시 생성합니다. 저장 기술은 아직 미정입니다.
- 외부 편집기로 HTML만 수정한 내용이 원본 데이터에 자동 반영된다고 가정하지 않습니다. HTML 재가져오기·독립 편집본 병합은 아직 지원 범위로 확정하지 않았습니다.
- 학생 원문·답지 원문·최초 인식 내용은 교사의 판정/분류 수정과 구분해 보존하는 안을 유지합니다.
- HTML에는 외부 리소스·자동 업로드를 넣지 않고 로컬 조회를 목표로 합니다. HTML 형식 자체가 무유출을 보장하지 않으며 실제 통신·저장 위치·접근 보호 검증이 필요합니다.
- PDF는 필요할 때 인쇄·배포용 출력으로 검토합니다. 이번 사용자 발화로 PDF 출력 기능까지 확정한 것은 아닙니다.

## 실제 작업

이번 변경은 방향과 편집 흐름 제안을 기록한 문서 변경입니다. 앱/HTML 편집 기능 구현, 브라우저 시험, 보안 검증, 앱 버전 태그 생성은 하지 않았습니다.
