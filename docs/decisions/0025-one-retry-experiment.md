# 0025 — 이력 제외 후 한 차례 재판독 실험

**159 사용자 정정으로 대상 선정·이력·선 해석이 대체됐습니다.** [결정0026](0026-current-run-retry-correction.md)을 우선합니다. 아래는 당시 실행 기록이며 새 요청에 적용할 규칙이 아닙니다.

2026-09-27, 대화154~158. 사용자가 157의 대상 집계 설명 후 채점 실행을 요청했습니다. 기존 검사 이력 전체를 제외하는 89개 후보 기준으로 실행했습니다. 실제 추가 OCR 이력만 제외하는 450개 안은 실행하지 않았습니다.

- 페이지 물리 조각마다 기존 `circle_search`, `count_search`, `retry_search` 중 하나라도 있으면 재시도하지 않습니다. 검사만 한 `attempts: 0`도 포함합니다. 기존 두 재판독 도구도 같은 이력 확인 함수를 사용합니다.
- 일반 필기 경로만 대상으로 합니다. 보호된 인쇄 선택 표시, 추출 후 제외 경로는 유지합니다. 157의 읽기 전용 후보 목록과 부모 결과 해시를 확인한 뒤 한 번 실행하며, 기존 출력 폴더를 덮어쓰지 않습니다.
- 선 분기: 채점용 좌표에서 사방 20픽셀 확장, 밝기와 국소 배경 대비 차이의 허용값 각각 20/255로 직접 연결된 부분을 검사합니다. 이 허용값은 Codex가 이번 시험용으로 정한 값이며 최적화되지 않았습니다. 연결된 테두리의 내부 획 접촉을 이유로 무조건 중단하던 제약은 이 실험 경로에 적용하지 않습니다. 보존할 인쇄 기호가 들어오거나 도형을 찾지 못하면 원래 조각의 크기 변경으로 전환합니다.
- 크기 변경: 처리 영상의 실제 필기 높이를 채점용 좌표로 환산하고 8픽셀 이하이면 해당 분기를 제외합니다. 비율을 유지해 필기 높이를 40으로 바꾸고 사방 24픽셀의 흰 여백을 더합니다. 기존 2배 확대 함수를 다시 적용하지 않습니다. 8픽셀 제한은 크기 변경 규칙이며 선·도형 분기 자체의 제한이 아닙니다.
- 선 검사와 크기 변경이 겹쳐도 OCR은 조각당 최대 한 번입니다. 선 확장 중간 PNG는 임시 폴더에서 처리 후 삭제합니다. 실제 OCR 입력과 보고서용 진단 사본은 로컬 근거로 보존합니다.
- 새 숫자 후보는 기존 0.8 기준, 숫자 형식 및 충돌 검사를 거칩니다. 이전에 낮은 점수로 읽힌 숫자라도 다른 유효 숫자로 바뀌면 충돌로 남깁니다. 높은 점수가 소속·복수 답·모름·답 개수 보류를 자동 해제하지 않습니다.
- 확장된 내부 획을 채택할 경우 실제 근거 범위를 70% 소속 조건으로 검사하고 소속이 달라지면 보류합니다. 원래 조각·위치·이미지는 보존하고 추가 OCR 근거는 결과 파일의 이름표에 표시합니다. 앱의 규칙표는 수정하지 않습니다.

실제 89개에는 새로 시도 가능한 `0` 또는 저점수 도형 분기 사례가 없었습니다. 선 11개도 내부 분리까지 진행되지 않아 이번 실제 OCR은 전부 크기 변경 입력입니다. 따라서 이번 결과로 새 선 연결·도형 제거의 인식 성능을 검증했다고 주장하지 않습니다.

이 변경은 개발용 실험 도구이며 운영 기본값 채택이나 독립 실행 앱 통합 완료가 아닙니다. [158 실행 기록](../conversations/2026-09-27-158.md)을 함께 확인합니다.
