# 0019 — 낮은 점수의 0·원문자 내부 재인식

2026-09-27 사용자 요청: `0` 또는 `①`처럼 원 안에 숫자가 있는 문자로 인식했고, 0.8 이하라 보류된 경우의 로직을 보충합니다. [실행139](../conversations/2026-09-27-139.md).

## 적용 조건

- 이미 2단계·사유6(신뢰도 부족)인 조각 중, 읽은 내용이 `0`/`０`이거나 숫자 원문자를 포함한 경우만 검사합니다. `O`, 일반 숫자, 알파벳 원문자는 대상이 아닙니다.
- 기존 판정은 점수0.8 이상을 통과시킵니다. 따라서 정확히0.8인 정상 후보를 새로 보류시키지 않으며 실제 추가 탐색 대상은0.8 미만입니다. 점수 경계는 변경하지 않습니다.
- 일반 학생 필기 경로만 처리합니다. 보존된 인쇄 번호·선택 표시 경로, 특수 의미 주석, 기존 재인식 충돌, 정렬 실패, 문항 밖 좌표는 제외합니다. 인쇄 선지 번호를 다시 읽어 학생 답으로 승격하지 않습니다.
- 기존132 개수 탐색 결과를 입력으로 받을 수 있지만 그 개수 탐색을 다시 실행하지 않습니다. 이 원 내부 탐색도 한 배치에서 한 차례만 실행하고, 이력이 있으면 재실행을 거부합니다.

## 분리와 추가 OCR

기존 `connected_circles` 검출을 재사용합니다. 밝기195 미만·면적8 이상 연결 성분을 검사하며, 내부 후보 성분의 모든 픽셀이 검출 타원의 정규화 반경0.9 안에 있어야 합니다. 원과 글자가 이어져 한 성분이 안팎을 가로지르면 처리하지 않습니다.

모든 내부 성분을 함께 유지합니다. 외부 성분이 원·상자에 해당할 수 있는 한 덩어리뿐인 경우로 한정하며, 바깥에 다른 글자가 있거나 원 후보마다 내부가 달라 모호하면 보류를 유지합니다. 이 제한은 복수 답 일부만 남기는 위험을 줄이는 보수적 조건이며 선택·취소 의미 판별을 보장하지 않습니다.

내부 성분 주변1픽셀의 회색 경계를 함께 보존하되 다른 검은 획에 닿으면 거부합니다. 기존 `reread_image`로 바깥 흰 여백 축소·최근접2배 확대·흰 여백10을 적용하고, 기존 로컬 OCR로 한 번 읽습니다. 원 입력·좌표·처리 경로는 그대로 두고 추가 입력·판독·점수·해시를 별도로 보존합니다. B/C 단계의 기존 수치는 변경하지 않습니다.

## 채택과 중단

- 새 판독도 기존 점수·답 형식 기준을 통과해야 후보로 채택합니다. 실패하면 원 판독과 보류를 유지합니다.
- 앞선 낮은 점수의 원문자도 유효한 숫자 집합으로 해석할 수 있었는데 새 숫자 집합과 다르면, 점수가 높더라도 `reread_conflict`를 기록하여 F06·4단계 사유10으로 보류합니다. `0`은 유효한 객관식 답 집합이 아닙니다.
- 답지·전사를 이용해 숫자를 선택하지 않습니다. 후보를 얻어도 F08(b)·F12·다른 문항 보류 규칙은 그대로 검사합니다.
- 원 조각과 내부 추가 이미지의 이름표·판독을 결과 파일에 각각 넣습니다. 앱 화면에 이 로직을 넣지 않습니다.

이 결정은 개발용 엔진 추가 단계입니다. 범용 원문자 정확도나 설치형 앱 완성을 뜻하지 않습니다. 사용 중인 표본을 진단해 만든 규칙이며 독립 평가 결과가 아닙니다.
