# 0023 — 각 단의 마지막 문항을 페이지 끝까지 확장

2026-09-27 사용자 요청: 최하단 필기를 각 단의 최하단 문제에 자동으로 연결합니다. [대화151](../conversations/2026-09-27-151.md).

후속 [대화152](../conversations/2026-09-27-152.md)에서 사용자가 면적70%를 지정했습니다. 이후 비교 기준은 하단 확장과70%를 함께 사용합니다. 아래 미선택 문구는151 당시 상태이며 CLI 호출에 `--minimum-overlap 0.7`을 명시합니다.

페이지 우선 OCR의 소속 연결 단계에서 같은 세트·페이지·단의 마지막 문항을 위치로 찾고, 아래 경계를 원본 페이지 이미지의 실제 높이까지 늘립니다. 특정 문항 번호나 y=1888을 하드코딩하지 않습니다. 현재 단은 기존 문항 범위의 좌우 좌표로 구분합니다. 자유 배치나 불규칙 단 검출을 추가하는 변경은 아닙니다.

문항 위쪽·좌우 경계, 마지막 문항 이외의 경계는 유지합니다. 따라서 페이지 중앙의 단 경계에 걸친 조각이나 좌우 바깥 조각을 임의로 한쪽에 배정하지 않습니다. 확장 후 면적 소속 판정은 기존 기본 방식 또는 사용자가 비교한 50%·60%·70% 설정을 따릅니다. 세 비율 중 기본값 선택은 아직 없습니다.

`tools/page_first_ocr.py`의 `assign`에 기본 적용하며 `prepare`와 OCR 자체는 그대로입니다. 이전 범위는 출력 문항의 `zone_before_bottom_extension`에 남기고 원본 자료와 지난 실행은 보존합니다. 페이지 이미지가 없거나 범위가 잘못됐거나 마지막 문항이 유일하지 않으면 중단합니다.

하단 로고·종이 흔적도 마지막 문항에 연결될 수 있습니다. 소속 배정은 답 채택이 아니며 기존 무결과·신뢰도·형식·충돌 검사 등을 생략하지 않습니다. 기존 문항 사진 `context`는 이번 소속 변경으로 재생성하지 않았으므로 하단 추가 필기는 조각/페이지 사진으로 확인해야 합니다. 최종 채점 및 검증 화면 갱신은 별도 작업입니다.
