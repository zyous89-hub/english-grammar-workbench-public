# 결정0032 — C 두 크기 합의와 낮은 원판독의 재판독 충돌 완화 E

- 날짜: 2026-09-27
- 상태: 사용자 요청 구현 및 단계별 134문항 검증 후 C·E 모두 채택.
- 근거: 대화166 (비공개 기록). 비교 기준은 대화165/결정0031의 B+D, 사용자안 28개·보조 제안안 26개 자동확정입니다.

## 채택 규칙

1. peel 실패 학생 필기는 B → C → D-1 순서로 처리합니다. C는 폭 2.5로 네모를 벗긴 뒤 세로 여백 16·24px의 두 판독이 같은 숫자 1~5·각 0.8 이상일 때 24px 판독을 사용합니다. C 통과 조각에는 D-1을 적용하지 않습니다. 기존 높이 40px·가로 여백 24px·전처리를 재사용하며 최고점으로 고르지 않습니다.
2. E는 원래 판독이 0.8 미만인 재판독 충돌만 완화합니다. B의 세 폭 또는 C·D의 두 크기가 같은 숫자·각 0.8 이상이어야 합니다. peel은 기존 peel 판독과 확인용 D-2 두 판독까지 모두 같은 숫자·각 0.8 이상이어야 합니다. 확인용 D-2만 기존 한 번 제한의 예외입니다.
3. 원래 판독이 0.8 이상이면 숫자 변경 충돌을 유지합니다. 합의가 없거나 판독 수·방법이 맞지 않아도 기존 충돌·보류입니다. `allow_low_confidence_consensus`는 기본값을 끈 채 명시적으로 적용합니다.
4. 같은 문항 안 다른 조각 간 F06은 완화하지 않습니다. F05/F08(b)/F10/F12·답지 개수·해상도·70% 소속·A를 유지합니다. 답지와 전사로 숫자를 고르지 않습니다.
5. 학생 필기 경로와 원래 `should_reread` 조건, 보호 인쇄 ①~⑤·ⓐ~ⓩ 제외는 그대로입니다. 원판독 빈칸·165의 보호 제외 4조각을 추가하지 않습니다. 160의 일반 크기 변경 3번도 계속 제외합니다. 기존 `result.json` 형식에 원판독·고정 판독·입력 이미지를 보존합니다.
