# D-004: 원본 확인과 이번 작업 범위

기록일: 2026-09-23. 연결: [대화 003](../conversations/2026-09-23-003.md).

## 사용자 확정

기존 이력을 유지해 지정 계정의 비공개 저장소에 저장합니다. 입력은 문제·정답·해설이며 분류는 없습니다. 앱 실행에 AI를 사용하지 않습니다. 후속 발화에서 자료는 나중에 제공하고 우선 프로젝트 내용만 파악하도록 범위를 조정했습니다.

## 확인한 사실

관련 스킬 두 묶음과 3장 참고 이미지, 시작용 사전, 집계 스크립트를 확인했습니다. 완성 HTML·실제 문제/답지 세트·교사 기준 분류는 확보되지 않았습니다. 집계 코드는 이미 분류된 자료가 필요하므로 그대로 옮겨도 해설 분류 기능이 생기지 않습니다.

## 개발 제안

첫 구현은 원문 보존·식별·입력 검증·저장/복원으로 좁히는 안입니다. 이유는 미확정 사전과 출력 양식에 의존하지 않기 때문입니다. 대안인 전체 UI/자동 분류 엔진 선구현은 원본과 다른 규칙을 고정할 위험이 있어 보류합니다. 상세 [이식표](../skill-mapping.md)를 참고합니다.

## 실제 적용과 한계

후속 요청 전에 입력 모듈과 시험 초안을 작성하기 시작했으나 실행·커밋하지 않았습니다. 후속 요청을 받아 이번 작업 중 새로 만든 초안 3개만 제거했습니다. 기존 파일·이력은 유지했습니다. 최종 변경에는 앱 코드가 없고, 앱 시험·분류 성능·패키징·오프라인 실행은 미실시입니다. 이는 실패한 성능 실험이 아니라 착수 범위 변경입니다.
