# D-016 — F08(a) 취소, F08(b) 유지

2026-09-26 사용자 확정: “F08(a)는 취소하자”, “F08(b)는 유지”. 이 결정은 0015 및 목록 117의 F08(a) 요구보다 우선합니다.

- 보존된 인쇄 번호가 채택 답과 다르다는 이유만으로 문항을 보류하는 F08(a)를 제거합니다. 보존 목록은 선택·체크·취소의 의미 판독 결과가 아닙니다.
- F08(b)는 유지합니다. 채택 후보 사각형과 점수 미달·형식 탈락 조각 사각형이 겹치면 문항을 3단계로 보류합니다. 번호가 다르더라도 겹침이 없다면 F08로 전파하지 않습니다.
- 조각 자체의 `choice_mark_review` 분류와 인쇄 번호 보존은 유지합니다. 해당 조각을 자동 답 후보로 승격하지 않습니다.
- F05·F06·F10·D12·G03 및 신뢰도 수치는 변경하지 않습니다. D11 조건부 결정과 F12 선택 작업은 여전히 미적용입니다.

사용자는 시험지 전체의 앞 절반인 **2~10쪽, 9쪽**을 지정했습니다. 36개 설정을 반복하지 않고 기준 설정 6000 / 0.7 / 3 하나만 사용합니다. 후속으로 동그라미 알파벳 보존 규칙도 적용하라고 요청했습니다.

076의 ①~⑤·ⓐ~ⓩ 보존 입력에서 해당 범위 66문항·581조각을 사용합니다. 075와 이미지가 바뀐 26조각은 새 OCR, 입력 및 처리 메타데이터가 같은 555조각은 기존 결과를 재사용합니다. 101과는 섞지 않습니다. 같은 071 정렬·구획을 사용하며 새 정렬이나 전체 36설정 실험은 하지 않습니다. 새 OCR에는 기존 로컬 모델·한자 차단·Python 통신 차단을 적용합니다.

이번 적용은 사후 분류 도구입니다. 운영 채점기 통합이나 전체 134문항 검증 완료로 표현하지 않습니다. 기존 v3와 원결과는 보존합니다.
