# 결정0033 — E 완화는 원래 숫자 한 글자에만 적용

- 날짜: 2026-09-27
- 상태: 구현 및 기존 134문항 검증 완료. 검증용 고정 버전.
- 근거: 대화167 (비공개 기록). 결정0032의 E 조건을 안전 보완합니다.

E는 원래 판독이 `1~5` 또는 `①~⑤` 중 한 글자일 때만 적용합니다. 기존 `to_digit` 검사를 재사용하므로 앞뒤 공백은 제거하되 괄호·마침표·여러 숫자는 허용하지 않습니다. 원래 점수 0.8 미만, 고정 복수 판독 합의, 방법별 판독 수와 나머지 안전장치는 그대로입니다. 원래 숫자가 여러 개면 재판독이 한 숫자로 합의해도 F06(re-read) 보류를 유지합니다. 답지를 보고 완화 여부를 결정하지 않습니다.

기존 166 판독을 재사용했으며 새 OCR은 0회입니다. 사용자안 자동확정/보류 33/101, 제안안 31/103과 모든 최종 답·채점 상태를 유지했습니다. 틀린 자동확정·오답→정답·정답→오답·기존 확정 상실은 모두 0개입니다. E 완화는 6개에서 4개로 줄었고 51·61번에 F06(re-read)가 복원됐습니다. 서로 다른 조각 간 F06 등 다른 규칙은 변경하지 않았습니다.

전체 74개 테스트 통과. 추가한 1개 테스트는 낮은 원판독 `①④` 등이 재판독 `4`로 줄어도 단일 정답 문항에서 보류되는지 확인하며 수정 전 실패와 수정 후 통과를 확인했습니다. 결과 HTML의 오래된 제목은 `OCR 결과 · 판독 및 채점 검증`으로 변경했습니다.
