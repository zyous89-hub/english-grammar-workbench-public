# D-001: 실행 중 AI 없는 앱

상태: 사용자가 명시한 요구. 기록일: 2026-09-23. 원문 확인 범위: 현재 대화의 저장 요청 이전 맥락.

## 요구

개발 과정에서는 AI를 활용할 수 있지만, 배포 앱의 실행에는 AI API나 로컬 언어모델·학습된 분류모델을 사용하지 않습니다.

## 제안하는 구현 방향

정해진 규칙·표현 사전·교사 확인·HTML 양식을 코드로 구현합니다. 기술 스택은 미정입니다.

## 고려해야 할 대가

범용 언어 이해를 주장하지 않습니다. 지원 범위, 규칙 충돌, 미분류, 수동 수정량을 측정해야 합니다. 개발 도구의 AI 사용 여부와 실행 중 AI 사용 여부를 분리해 설명합니다.

## 검증

대상 운영체제에서 네트워크 차단 실행, 의존성 점검, 입력부터 출력까지 시험이 필요합니다. 아직 실행하지 않았습니다.
