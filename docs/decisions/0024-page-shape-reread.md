# 0024 — 페이지 조각의 도형 재판독을 소속 배정 전에 연결

2026-09-27 사용자 요청: 도형 재판독까지 포함해 다시 채점합니다. 대화153 (비공개 기록).

최신 순서는 페이지 전체 추출 → 최초 OCR → 분리 가능한 도형 내부의 한 차례 추가 OCR → 하단 확장·70% 문항 소속 연결 → 두 안 순차 채점입니다. 공통 물리 조각을 한 번 재판독하고 두 정책이 결과를 공유합니다. 이미 수행한 최초 OCR은 이번에 재실행하지 않습니다.

기존 `circle_inner_search.run`은 문항별 조각의 전체 사각형이 문항 안에 있어야 처리했습니다. 이를 그대로152 결과에 호출하면70%로 인정된 경계 조각이 제외되고, 한 조각이 두 문항에 연결된 경우 중복 처리가 생길 수 있습니다. 질문 ID가 없는 페이지 조각을 지원하도록 확장해 실제 페이지 경계와 정렬만 검사하고, 재판독 뒤 소속을 적용합니다. 혼합 입력은 거부하며 기존 문항별 호출은 원래 범위 검사를 유지합니다.

결정0020의 대상/판정은 유지합니다. 낮은 점수 일반 필기 중 독립된 내부 획을 품은 동그라미·네모를 검사하고, 분리 가능한 테두리만 제거합니다. 0.8 이상 유효 답을 후보로 채택하며 충돌·F08(b)·F12 등 후속 검사를 생략하지 않습니다. 무결과(사유5), 인쇄/선택 표시, 특수 의미 등 기존 제외 조건을 임의로 넓히지 않습니다. 추가 답 개수 OCR은 별도 기능이며 이번에 실행하지 않습니다.

추가 OCR 이력은 `circle_search`로 공통 결과에 보존되고, 한 번 검사한 배치의 재실행을 차단합니다. 원조각·점수·새 내부 이미지·새 점수를 결과 근거로 전달합니다. 페이지 최초 OCR의 시간/범위 정보와 추가 OCR 시간은 구분해서 보존합니다. 로컬 모델만 사용하며 기존 Python 소켓/DNS 차단 경로를 유지합니다(운영체제 전체의 무통신 인증을 뜻하지 않음).

개발용 실행:

```text
python -m tools.circle_inner_search <최초 페이지 OCR 폴더> <원자료 폴더> <새 재판독 폴더> <로컬 모델 폴더>
python -m tools.page_first_ocr assign <원자료 폴더> <새 재판독 폴더>/shared-batch <새 소속 폴더> --annotations <기존 의미 주석 결과> --minimum-overlap 0.7
```

그 뒤 기존 단계 분류(F12 활성)·두 원 예외 정책 비교·결과 내보내기를 수행합니다. 하나의 앱 실행 버튼에 통합된 완성 앱은 아직 아닙니다.
