# 0010 — 객관식 확정 후 표기 방식별 판독

2026-09-24. 사용자 제안에 따른 설계 방향. 구현·학습·성능 검증 전. 세부 충돌 처리와 적용 단위는 아래 assistant 제안으로 구분합니다.

## 결정 방향

이 단계의 입력은 이미 객관식으로 확인된 문항입니다. 객관식/주관식 분류를 다시 하는 대신 학생 답의 표기 방식에 맞는 판독 절차를 준비합니다. 학생이 직접 번호를 쓴 답을 둘러싼 원·네모와, 원본에 인쇄된 번호에 붙인 원·체크를 구분합니다. 도형 모양만으로 같은 입력으로 취급하지 않습니다.

| 사용자 제시 방식 | 필요한 판독 | 채점에 전달할 것 |
|---|---|---|
| 번호를 따로 쓰고 원·네모 등으로 강조 | 추가된 필기 숫자를 OCR로 읽고 도형은 답 위치의 보조 단서로 사용. 무조건 도형 제거/안쪽 자르기를 하지 않음 | 학생이 쓴 선택 번호 집합 |
| 선지에 체크·동그라미 등으로 직접 표시 | 원본 선지 위치에 추가된 표시를 연결하고 선택 의미 판별. 인쇄 숫자 자체를 새 손글씨로 읽는 것이 아님 | 표시된 선지 번호 집합 |
| 선지에 X·사선으로 제외 표시를 하며 풀고 답을 따로 씀 | 별도 필기 답과 선지 위 제외 흔적을 함께 검출하되 역할 분리. 별도 필기 답은 OCR 경로 사용 | 별도로 쓴 최종 선택, 제외 흔적은 보조 기록 |

정오답 비교는 하나의 공통 채점 규격을 사용합니다. 표기 방식마다 정답 기준을 바꾸지 않습니다. 점수는 계산하지 않고 학생 선택 확정 후 답지와 비교합니다. 학생 이미지와 판독은 로컬 처리합니다.

## 세부 적용 — assistant 제안

- 적용 단위는 학생 전체가 아니라 문항입니다. 한 문항에서도 숫자·선지 표시·제외 흔적이 함께 나타날 수 있어 복수 경로를 허용합니다. 한 가지 방식으로 먼저 확정한 뒤 다른 표시를 버리지 않습니다.
- 문항별 공통 후보 수집 후 별도 숫자, 선지 직접 표시, 취소·제외 흔적을 각각 살펴봅니다. 방법 분류 실패 시 다른 경로를 배제하지 않고 보류합니다. 세 개의 별도 AI 모델이 필수라는 뜻은 아닙니다.
- X·사선을 무조건 제외로 확정하지 않습니다. 사용자의 표기 습관이나 주변 맥락상 선택/취소 의미가 명확하지 않으면 보류합니다.
- 명확한 별도 답과 제외 흔적만 있는 경우 별도 답을 사용합니다. 별도 답이 없다고 제외되지 않은 나머지 선지를 자동 선택하지 않습니다.
- 별도 답과 직접 선택 표시가 일치하면 통합합니다. 서로 다르거나 별도 답이 명확한 제외 표시와 충돌하면 어느 한쪽을 무조건 우선하지 않고 보류합니다. 명확히 두 개를 최종 답으로 표시한 경우만 단일 선택 복수 응답 오답 정책을 적용합니다.
- 원·네모·체크 등 모양 목록은 지원을 검증할 범위이지 현재 성공 보장이 아닙니다. 원형 필수 조건은 두지 않습니다. 필기 숫자·표시 의미·최종 선택을 각각 검토한 라벨이 필요합니다.

## 이유와 증거

선지 직접 표시 시험 (비공개 기록)에서는 변화 위치를 찾았지만 인쇄 글자를 OCR로 읽는 것만으로 선택/제외 의미를 확정할 수 없었습니다. 따라서 기존 숫자 OCR에 모든 표기를 강제하는 방식보다 역할을 분리합니다. 기존 표본에서 튜닝한 결과를 새 학생에 대한 독립 평가로 부르지 않습니다. 후속 검증은 방식별 오류와 혼합·충돌·보류를 함께 기록합니다.
