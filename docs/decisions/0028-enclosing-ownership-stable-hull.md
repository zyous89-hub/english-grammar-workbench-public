## A — 소속 보완

재판독까지 반영한 뒤 기존 70% 규칙으로 단일 배정된 유효 답 후보를 고정합니다. 소속 미확정 조각이 후보 `box` 면적의 80% 이상을 감싸고, 감싼 후보들이 모두 같은 문항에 속하면 그 문항으로 배정합니다. 여러 문항의 후보를 함께 감싸거나 유효 기준 후보가 없으면 기존 소속 보류를 유지합니다. 새 배정을 기준으로 연쇄 배정하지 않습니다. 답지·확인 전사는 소속 결정에 사용하지 않습니다.

선택 옵션 `--enclosing-candidates`로 제공하며 기본값은 꺼 둡니다. 기존 70% 경로의 결과를 그대로 재현하는 회귀 검사를 유지합니다. 이번에는 3조각이 28·29·90번으로 단일 배정됐고, 28·90번이 새로 자동 확정됐습니다.

## B — 붙은 테두리의 세 폭 판독

폭 2.0·2.5·3.0을 각각 한 번 읽고, 세 결과 모두 같은 1~5 숫자이며 점수가 각각 0.8 이상일 때 2.5 결과만 새 후보로 사용합니다. 원문자 ①~⑤와 일반 숫자는 합의 확인에서 동등하게 비교합니다. 원판독과 새 숫자가 다르면 F06(re-read) 보류를 유지합니다. 원판독·세 판독·PNG는 근거로 보존합니다. 중간 변환이 없으면 해당 조각의 남은 폭을 중단합니다.
