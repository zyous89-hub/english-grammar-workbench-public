# 0020 — 동그라미·네모 내부 재인식과 기존 문항 검사 유지

2026-09-27 사용자 승인. 대화140 (비공개 기록). 결정0019의 문자 기반 대상 선정과 원만 찾는 제한을 이 결정으로 보완합니다.

1. 이미 신뢰도 부족으로 보류된 일반 필기 조각에서 **이미지의 동그라미·네모 테두리**를 찾습니다. OCR이 `①` 대신 일반 숫자나 다른 문자로 읽었더라도 실제 도형이 있으면 검사합니다. 0.8 이상 통과 기준·빈칸/인쇄 제외·선택 표시 경로·특수 의미·기존 충돌 검사는 그대로입니다.
2. 다른 독립된 획을 품고 있는 테두리만 제거합니다. 닫힌 공간만 있고 별도 내부 획이 없는 `0·6·8·9` 자체는 대상이 아닙니다. 내부 획과 테두리가 이어져 있으면 그 테두리는 억지로 지우지 않습니다.
3. 내부의 모든 유효 연결 성분을 함께 유지합니다. 동그라미와 네모가 중첩됐으면 같은 내부 글씨를 둘러싼 분리 가능한 테두리를 함께 제거합니다. 도형마다 다른 글씨를 품거나, 외부에 남는 글씨가 있거나, 경계를 가로지르는 획 때문에 모호하면 추가 인식을 하지 않습니다.
4. 분리된 이미지에 기존 여백·2배 확대 처리를 적용해 OCR을 한 번 수행합니다. 새 결과가0.8 이상이고 기존 숫자·복수 숫자 형식을 통과하면 **답 후보**로 채택합니다. 이전 숫자와 다르면 충돌로 보류합니다. 답지에 맞춰 선택하지 않습니다.
5. 후보 채택 뒤에도 F06 충돌·F08(b) 미해결 조각·F12 명시 개수·답지·정렬·특수 표시 검사를 거칩니다. 재인식 점수만으로 문항을 확정하지 않습니다.

원·처리 이미지와 양쪽 판독을 엔진 결과 파일에 보존합니다. 기존 `circle_search` 이력 필드와 실행 명령을 유지해 종전 배치의 중복 재실행도 차단합니다. 앱 화면·파일 계약·교사 수정 보존 방식은 변경하지 않습니다.

네모는 충분한 크기의 볼록 사각 윤곽에서 변 길이와 모서리 각도를 검사하고, 내부에 여유를 두어 판별합니다. 기울어진 손그림 네모는 허용하지만 범용 도형·취소 의미를 판별하는 기능은 아닙니다. 실제 자료에서 채택된 설정이며 독립 평가와 구분합니다.
