# 객관식 채점 규격 초안

작성: 2026-09-24. 상태: 사용자와 협의 중. 구현·학습·채점 성능 검증 전. 문서 초안 번호는 앱 버전이 아닙니다.

## 확정된 사용자 원칙

- 점수·배점·부분점수를 매기지 않습니다. 정오답과 사유를 기록하는 규격입니다.
- 단일 선택 문제에서 최종 선택이 명백히 여러 개이면 복수 응답으로 기록하고 오답 처리합니다. 취소·수정 판독이 애매한 경우와 구분합니다.
- 학생 답안을 원 모양으로 제한하지 않습니다.
- 원본 선지에 근거해 학생 선택을 파악하는 방향을 검토합니다. 선지 내용은 정답지가 아닙니다.
- 오답을 정답으로 바꾸는 오류를 최우선으로 막습니다. 오류가 절대 없다고 보장한 구현은 아직 없습니다.
- 학생 스캔·필기·성적은 로컬에 둡니다. 원본 유형 분석에 API를 쓰더라도 학생 자료를 전송하지 않습니다.

## 입력과 문항 등록 — 제안

필기 없는 원본, 학생 스캔, 해당 교재·판본·페이지의 답지를 연결합니다. 원본을 기존 두 폴더 구성에서 어떻게 제공받을지는 아직 미정입니다. 교재·판본·인쇄 페이지·문항 번호로 연결하고 소문항이 있으면 별도 식별합니다. OCR이 감지한 순서만으로 답지를 연결하지 않습니다.

문항마다 지시문, 선지 번호·내용·위치, 하나/여러 개 선택 조건, 답지의 정답 집합, 답지 근거와 검토 상태를 저장합니다. 선지 수는 항상 5개라고 가정하지 않습니다. 선지 누락·중복 번호·지시문과 답지 충돌·페이지 대응 불명은 채점 보류입니다. 공식 정답 대신 모델의 문제 풀이를 대입하지 않습니다. 초기 교재 등록 시 선지·유형·답지 대응을 교사가 확인하는 흐름을 제안합니다.

## 학생 답 판독 — 제안

1. 원본과 학생 페이지를 정렬하고 문항별 학생 추가 표시를 찾습니다. 정렬·영역 추출 실패를 학생 무응답으로 간주하지 않습니다.
2. 별도 필기 번호는 문자 인식으로, 선지 위 표시들은 위치와 표시 형태로 읽습니다. 학생 글씨 또는 표시가 원형인지 여부를 필수 조건으로 쓰지 않습니다.
3. 원시 판독과 근거 이미지를 보존하고 확정 가능한 선택 번호 집합으로 변환합니다. `③`과 `3`처럼 표기만 다른 번호는 통일할 수 있습니다. 다른 숫자로 고치거나 답지 정답으로 맞추지 않습니다.
4. 같은 선지를 반복해 표시한 것이 명확하면 하나의 선택으로 기록하되 원시 표시 기록은 남깁니다. 서로 다른 위치의 번호·표시가 충돌하면 크기·진하기·정답 여부만으로 우선하지 않습니다.
5. 취소·지움·수정은 최종 선택을 확인할 근거가 충분할 때만 반영합니다. 밑줄·메모·옆 문항의 표시·예제와 답안을 구분하지 못하면 보류합니다.
6. OCR 점수 하나만으로 자동 확정하지 않습니다. 영역 완전성·문항 연결·표시 충돌을 함께 확인하는 자동 확정 기준은 별도 데이터로 검증 후 정합니다. 현재 초안에 임의 점수 임계값을 넣지 않습니다.

## 판독과 채점 상태 — 제안

판독 상태는 선택 확인, 무응답 확인, 판독 보류로 분리합니다. 채점 상태는 정답, 오답, 채점 보류로 분리하고 사유를 추가합니다. 무응답 여부가 확인된 경우만 무응답 사유의 오답으로 처리하는 안을 제안합니다. 모델 출력이 비었다는 이유만으로 무응답을 확정하지 않습니다.

| 조건 | 처리 초안 |
|---|---|
| 단일 선택에서 최종 선택 1개, 답지와 일치 | 정답 |
| 단일 선택에서 최종 선택 1개, 답지와 불일치 | 오답 |
| 복수 선택에서 선택 집합이 정답 집합과 완전히 일치 | 정답. 선택 순서는 무관 |
| 복수 선택에서 일부 누락 또는 추가 | 오답으로 기록하고 누락·추가 선택을 표시하는 안. 점수 계산 없음 |
| 단일 선택에서 최종 선택이 명백히 2개 이상 | 복수 응답 사유의 오답. 사용자 확정 |
| 답란·주변·선지 영역이 정상 검출됐고 무응답 확인 | 무응답 사유의 오답 제안 |
| 흐릿함·잘림·수정 충돌·학생 선택 불명 | 판독 보류 및 채점 보류 |
| 답지 없음·불명·판본/번호 대응 불명 | 채점 보류. 학생 선택 판독은 별도 보존 가능 |

복수 선택의 예시는 가상입니다: 정답 {2,4}, 학생 {4,2}는 일치. 학생 {2} 또는 {2,3,4}는 불일치. 이 예시를 실제 시험 결과로 기록하지 않습니다.

사용자 지시로 총점·백분위 점수·배점·부분점수를 계산하지 않습니다. 정오답 개수와 사유를 기록하는 안입니다. 보류가 하나라도 있으면 전체 채점 완료로 표시하지 않습니다. 전체 문항 수 = 정답 + 오답 + 채점 보류가 맞아야 하며 오답 안의 무응답·복수 응답 사유는 중복 집계하지 않습니다. 내부 OCR 신뢰도는 학생 점수와 별개이며 그 수치만으로 정답을 확정하지 않습니다.

## 기록·검토 — 제안

로컬 기록은 세트/문항 ID, 학생 선택, 정답, 판독·채점 상태, 사유, 원본 및 학생 근거 영역, 모델·규칙 버전, 교사 수정 전후 값과 시각을 포함합니다. 교사 수정 후 재채점하되 처음 판독을 덮어쓰지 않습니다. 학습 라벨은 교사가 확인한 학생의 실제 선택이며 답지 정답과 분리합니다. 보류 자료를 추정 라벨로 학습시키지 않습니다.

## 첫 검증 단위 — 제안

기존 9문항은 개발 표본으로 두고 잘린 2번 영역을 보완하는 전후 비교와 나머지 문항 회귀를 구분합니다. 번호만 쓰기·선지 직접 표시·복수 선택·취소·수정·무응답·범위 밖 필기를 포함한 표본을 추가 확보하고 교사 기준 전사를 만듭니다. 없는 표기 표본을 확보했다고 표현하지 않습니다.

평가에서는 문항 연결 오류, 영역 누락, 선택 번호 오류, 잘못된 무응답, 오답→정답, 정답→오답, 보류 건수와 검토 시간을 함께 기록합니다. 자동 처리율을 높이기 위해 보류를 정답으로 바꾸지 않습니다. 검증 표본에서 오답→정답이 0건이어도 모든 미래 입력의 무오류를 의미하지 않습니다. 학습·튜닝과 별도 학생·교재 평가는 분리합니다.

## 현재 논의 중

사용자는 점수를 매기지 않도록 정정했고 단일 선택의 명백한 복수 응답은 오답으로 확정했습니다. 복수 선택은 정답 집합과 완전히 일치할 때 정답으로 기록하는 안을 제안합니다. 지원 표기 범위·자동 판독 확정 기준 및 나머지 제안 항목은 추후 검토합니다. 부분점수·배점 정책은 논의 대상에서 제외합니다.
